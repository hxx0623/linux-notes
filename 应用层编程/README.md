## 三、⭐ 按难度分级（**不是按集数平均**）

**同样"1 集"，难度差 10 倍**：`78 操作系统软件分层`（6:30，纯概念）vs `37 execve`（34 分钟，要写透）。

| 级 | 类型 | 集数 | 特征 | 每天能做几集 |
| --- | --- | --- | --- | --- |
| **A** | **概念课** | **48 集** | 听懂就行，可倍速、可批量 | **6–12 集** |
| **B** | **动手课** | **69 集** | **必须写代码并调试** | **1–4 集** |
| **C** | 快进/跳 | **13 集** | 已有基础或环境不符 | 一批过 |

### 时间账（关键结论）

| 级 | 视频时长 | 系数 | **实际耗时** |
| --- | --- | --- | --- |
| A 概念 | 6.5 h | ×1.3 | **8.5 h** |
| **B 动手** | **16.3 h** | **×2.5** | **41 h** |
| C 快进 | 2.5 h | ×0.6 | **1.5 h** |
| **合计** | 25.2 h | | **≈ 51 h**（按块细分约 63 h） |

> 🔑 **69 集动手课（53% 集数）→ 占 80% 时间**。**"哪天学多少集"没意义，要看那天是概念课还是写代码。**

### 真实周期（**取决于每天投入小时数**）

| 每天投入 | 总周期 |
| --- | --- |
| 1 小时（韩顺平那会儿的常态） | ≈ 7 周 |
| 2 小时 | ≈ 3.5 周 |
| 3 小时 | ≈ 3 周 |

## 四、和已有知识的对应关系（**这决定你能多快过**）

| 本课内容 | 你已经会的 | 差什么 |
| --- | --- | --- |
| 09–14 编译流程 | C 语言第 1 课四阶段 | **链接细节**（符号表、动态库） |
| 15–19 Makefile | 第 8 课基础 Makefile | **变量/自动推导/伪目标** |
| 20–28 文件 IO | 第 7 课 `fopen/fgets/mycat` | 基本没有，可快过 |
| **29–33 系统调用** | —— | ⭐ **全新**（库函数 vs 系统调用的区别、fd） |
| **34–54 进程** | 韩顺平课的 `ps`/`systemctl`（**会用**） | ⭐⭐ **不会写**（fork/exec/wait） |
| **55–75 线程** | 韩顺平课的 `ps -T`（知道有线程） | ⭐⭐ **全新**（pthread + 同步） |
| **94–125 网络** | 韩顺平课的 `ss`/`tcpdump`（**会看**） | ⭐⭐ **不会写**（socket 编程） |
| 76–93 内核原理 | 香橙派课看过 `zygote/system_server`、内核编译 | 系统化补齐 |

> 🎯 **一句话**：**韩顺平教你"用" Linux，这门课教你"写" Linux 程序。**
> 你之前学的 `ps`、`ss`、`tcpdump` 都是**这门课要写的东西**的工具 —— 现在从"用工具"变成"造工具"。
