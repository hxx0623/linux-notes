## 一、为什么不用 Windows 的 VS？VS / VS Code / vim 怎么选

### 核心原因：**这门课的代码必须在 Linux 上编译运行**

```c
fork()            ← Linux 系统调用，Windows 没有
pthread_create()  ← Linux 线程库
open/read/write   ← POSIX 系统调用
socket()          ← Windows 有，但是另一套 API（Winsock）
    ↓
代码只能在【Linux】上编译运行
    ↓
VS 装在 Windows 上，它编不了这些
    ↓
VS 顶多当"编辑器"，编译运行还是要在 Linux 里 —— 那就不值几 GB 的代价
```

### 三者对比

| | **vim**（现在用的） | **VS Code** | **Visual Studio (VS)** |
| --- | --- | --- | --- |
| 大小 | 内置 | 几百 MB | **几 GB ~ 十几 GB** |
| 定位 | 编辑器 | **轻量编辑器** + 插件 | 完整 IDE |
| 平台 | 全平台 | 全平台 | Windows/macOS 为主 |
| 代码补全 | 需配 `ctags`/`coc.nvim` | ⭐ 自带 IntelliSense | ⭐⭐ 最强 |
| 图形化调试 | `gdb -tui` / `cgdb` | ⭐ 内置 | ⭐⭐ 最强 |
| 跳转定义 | `cscope`/`gtags` | ⭐ 自带 | ⭐⭐ 最强 |
| 在 Linux 上编 C | ⭐ **原生** | 通过 Remote-SSH | 需"Linux 开发"工作负载 |

### 什么时候该换

| 情况 | 建议 |
| --- | --- |
| 现在（基础练习，代码短） | ✅ **vim + gcc + gdb 够用** |
| 觉得补全/跳转太痛苦 | ⭐ **VS Code + Remote-SSH 连虚拟机**（比 VS 轻，代码仍在 Linux 跑） |
| 从不用 Windows VS | —— |

**结论：VS 那 4 集（05–08）可以跳；如果以后想升级体验，用 VS Code + Remote-SSH，不用 VS。**

## 三、三门课是什么关系

| 课程 | 教你什么 | 一句话 |
| --- | --- | --- |
| **韩顺平 153 集** | **用** Linux | `ps`、`ss`、`tcpdump`、`systemctl` |
| **C 语言 9 课** | **写** 的语法 | 指针、结构体、函数指针、文件 IO |
| **尚硅谷 130 集** | ⭐ **写** Linux 程序 | 把"用的那些工具"自己造出来 |

**对应关系**：
- 学过 `ss` 看端口 → 这门课学**写 socket 服务端**
- 学过 `ps` 看进程 → 这门课学 **`fork` 造进程**
- 学过 `tcpdump` 抓包 → 这门课学**三次握手怎么在自己程序里体现**

### 和 C 语言课的重叠

| 重叠部分 | 怎么处理 |
| --- | --- |
| GCC 编译四阶段（09–13） | **快进**（第 1 课已实测） |
| 文件 IO 七个函数（20–26） | **快进**（第 7 课全写过，`mycat` 和 cat 逐字节一致） |
| Makefile（15–19） | **要学** —— 自动推导/伪目标/忽略错误是第 8 课没讲的 |
| 链接（14） | **要学** —— 比第 1 课深（符号解析、动态库） |

## 六、以后可能还会问的（先备答案）

### 为什么不直接在板子上写这些程序？
**可以，而且最终就该在板子上写。** 但学习阶段用 Ubuntu VM 更快：
- 编译快、有 gdb/strace、崩了不影响板子
- **`fork`/`pthread`/`socket` 在 VM 和板子上完全一样**（同一套 POSIX API）
- 区别只在**性能和外设**（GPIO/I2C 那些）

### 学完这 130 集能干什么？
- 写**多进程/多线程的服务器**（并发处理）
- 写**网络通信程序**（TCP/UDP 客户端服务端）
- 写**守护进程**（后台服务）
- 用 **epoll** 做高并发
- ⭐ **这些正是"安卓容器多开"、"云手机"、"边缘设备服务"的底层能力**

### 和 C 语言 9 课的关系会不会重复？
**不会**。C 语言课是**语法**，这门课是**系统 API**。
语法不会用系统 API，系统 API 不懂语法也写不了 —— **两块都必须有。**
