## 一、结构体基础

```c
struct Point {          /* ⚠️ 结尾的分号千万别漏 */
    int x;
    int y;
};

struct Point p1 = {3, 4};              /* 按顺序 */
struct Point p2 = {.x = 10, .y = 20};  /* 指定成员（C99，推荐） */

p1.x = 100;            /* 访问成员用【点号】 */
```

## ⭐ 内存对齐（嵌入式必知）

```c
struct A { char c; int i; };     /* 内容 5 字节 → sizeof = 8 */
struct B { int i; char c; };     /* 内容 5 字节 → sizeof = 8 */
struct Student { char name[20]; int age; float score; };  /* 20+4+4 → 28 */
```

**实测**：`sizeof(struct A) = 8`、`sizeof(struct B) = 8`、`sizeof(struct Student) = 28`

```
struct A { char c; int i; };
┌────┬─────┬─────┬─────┬──────────────┐
│ c  │ pad │ pad │ pad │      i       │
│1字节│ 空  │ 空  │ 空  │    4字节      │
└────┴─────┴─────┴─────┴──────────────┘
      ↑ 3 字节填充，让 int 落在 4 的倍数地址上
```

**为什么**：CPU 访问 4 字节 `int` 时地址必须 4 字节对齐，否则慢（某些 ARM 直接报错）。

> 📌 **所以协议/寄存器结构体不能靠 `sizeof` 算偏移** —— 要知道每字段偏移（`offsetof`），
> 协议结构体常用 `__attribute__((packed))` **取消填充**。

## 二、⭐ 结构体指针 + `->`（本课核心）

```c
struct Point  p  = {3, 4};
struct Point *pp = &p;

pp->x        /* ⭐ 最常用 */
(*pp).x      /* 完全等价 */
*pp.x        /* ❌ 错！. 优先级高于 * */
```

**实测**：
```
(*pp).x = 3        pp->x = 3
pp->x = 100 之后：p.x = 100     ← 通过指针改了原件
```

### 指针算术按【结构体大小】走

```
sizeof(struct Point) = 8
pp     = 0x7fff3a3610f0
pp + 1 = 0x7fff3a3610f8        ← 差 8 字节，正好一个结构体
```

## 三、⭐ 值传递 vs 指针传递

```c
struct Big { int data[100]; };        /* 400 字节 */

void by_value(struct Big b)   { b.data[0] = 999; }    /* 复制 400 字节 */
void by_pointer(struct Big *b) { b->data[0] = 999; }  /* 只复制 8 字节（地址） */
```

**实测**：
```
by_value 后:   data[0] = 1    ← 没变（改的是副本）
by_pointer 后: data[0] = 999  ← 变了
sizeof(struct Big) = 400 字节
```

**内核里几乎只传指针的三个理由**：
1. 值传递要**复制整个结构体**（大结构体慢）
2. 值传递**改不了原数据**
3. 大结构体放栈上**可能爆栈**

## 四、结构体数组 = "设备表"

```c
struct Device { char name[16]; int id; int irq; };

struct Device devs[3] = {
    {"uart0", 0, 33},
    {"spi1",  1, 44},
    {"gpio",  2, 55},
};

/* 方式 1：下标 */
for (int i = 0; i < 3; i++)
    printf("%s id=%d irq=%d\n", devs[i].name, devs[i].id, devs[i].irq);

/* 方式 2：⭐ 结构体指针遍历（内核写法） */
struct Device *p = devs;
for (int i = 0; i < 3; i++, p++)     /* p++ 前进一个【结构体】 */
    printf("%s id=%d irq=%d\n", p->name, p->id, p->irq);
```

**实测两种遍历输出完全一致**。内核里到处是 `for (...) { dev = &devices[i]; dev->name; }` 这种形状。

## 五、⛔ 两个踩到的坑

### 坑 1：`for` 的三段用**分号**，不是逗号

```c
for (int i = 0, i < 3; i++)     /* ⚠️ 错：逗号 */
for (int i = 0; i < 3; i++)     /* ✅ 对：分号 */
```

### 坑 2：⭐ **一个语法错误会引起"错误雪崩"**

```
table.c:27:28: error: expected '=', ',', ';', 'asm' or '__attribute__' before '<' token
table.c:32:10: error: expected expression before 'return'
table.c:33:1: error: expected expression before '}' token
```

**三个 error，只有第一个是真的**；后面的是"语法树塌了"的连带报错。

> 🔑 **读报错铁律**：**只看第一个 error**，修掉再重新编译。
> 盯着第 3、4 个报错找问题，只会浪费时间。

## 六、结构体三个坑

| 坑 | 现象 |
| --- | --- |
| 定义漏分号（`}` 后没 `;`） | 一堆莫名其妙的错误 |
| **结构体不能用 `==` 比较** | 编译错误（内部 padding 值不确定）→ 逐成员比 |
| `*pp.x` | 编译错误（应为 `pp->x` 或 `(*pp).x`） |

## 七、LED 结构体（实测写对了）

```c
struct Led {
    char name[16];
    int  pin;
    int  on;
};

void led_init(struct Led *led, const char *name, int pin)
{
    strncpy(led->name, name, sizeof(led->name) - 1);
    led->name[sizeof(led->name) - 1] = '\0';    /* ⭐ strncpy 不保证补 '\0'，必须手动 */
    led->pin = pin;
    led->on  = 0;
}

void led_on(struct Led *led)
{
    led->on = 1;
    printf("%s: 已点亮\n", led->name);          /* ⭐ 用 led->name，不要硬编码 */
}

void led_print(const struct Led *led)           /* const = 承诺只读 */
{
    printf("%s: pin=%d, 状态=%s\n", led->name, led->pin, led->on ? "亮" : "灭");
}
```

**要点**：
- `const struct Led *` = "我只读，不改" —— **内核里到处是 const**
- `strncpy` + **手动补 `\0`** 是标准安全写法
- 打印用 `led->name`，别硬编码 "status"（否则换名字就错）

### 输出（实测）
```
status: pin=12, 状态=灭
LED status (pin 12) 已点亮
status: pin=12, 状态=亮
LED status (pin 12) 已灭灯
```
