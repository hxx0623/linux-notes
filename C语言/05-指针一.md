# C 语言 第 5 课：指针（一）

> 2026-11-16。**一句话**：**指针就是一个存着地址的变量；`*p` = 去那个地址干活。**

---

## 一、为什么 C 必须有指针

> **C 只有"值传递"。想让函数改调用者的变量，只能传"地址"给它。**

`scanf("%d", &x)` 为什么要 `&`？
因为 `scanf` 要**改你的 x**，它只能拿到 x 的地址。

---

## 二、三个符号

| 写法 | 读作 | 干什么 |
| --- | --- | --- |
| `int *p` | p 是**指向 int 的指针** | **声明**时 `*` 表示"这是个指针" |
| `&x` | x 的**地址** | **取地址**（address-of） |
| `*p` | p **指向的东西** | **解引用**（dereference） |

⚠️ **同一个 `*`，声明里和表达式里是两个意思**：
`int *p;` → "这是个指针"；`*p = 100;` → "解引用"。

### 实测（`ptr.c`）

```
x    的值     = 42
&x   的地址   = 0x7fff53004f4c
p    里存的值 = 0x7fff53004f4c    ← 和 &x 完全相同 ✅
*p   指向的值 = 42
&p   自己的地址 = 0x7fff53004f50  ← 比 &x 大 4 字节
*p = 100 之后：x = 100
```

⭐ **`&p - &x = 4 字节`** = 正好一个 int → 说明 x 和 p 是**栈上相邻的两个变量**。

## 三、⭐ 指针作参数（本课核心）

```c
void bad_swap(int a, int b)     /* 值传递：a、b 是副本 */
{
    int t = a; a = b; b = t;
}

void good_swap(int *a, int *b)  /* 地址传递：能改原件 */
{
    int t = *a; *a = *b; *b = t;
}

bad_swap(x, y);      /* 把 x 的【值】复制给 a */
good_swap(&x, &y);   /* 把 x 的【地址】给 a */
```

**实测输出**：
```
交换前: x=1 y=2
  函数内: a=2 b=1（改的是副本）
bad_swap 后: x=1 y=2   ← ⚠️ 没变！
good_swap 后: x=2 y=1  ← ✅ 变了！
```

## 四、指针与数组（同一个东西的两种写法）

```c
int a[5] = {10,20,30,40,50};
int *p = a;              /* 数组名【就是】首元素地址，不用 & */
```

**实测**：`a`、`&a[0]`、`p` **三个地址完全相同**。

| 认知 | 说明 |
| --- | --- |
| ⭐ **`a[i]` 就是 `*(a + i)`** | 数组下标只是指针运算的语法糖 |
| ⭐ **`p++` 按元素前进** | `int *p` 的 `p++` 前进 **4 字节**（`sizeof(int)`），不是 1 字节 |

**实测**：`p = a;` → `*p = 10`；`p++` → `*p = 20` ✅

> 这解释了为什么 `strlen` 可以写成 `while (*s++) n++;`。

## 五、⭐ 用指针"返回多个值"（C 最重要的模式）

C 的 `return` **只能返回一个值**。要返回多个 → **传入指针，让函数往里写**。

```c
void minmax(int a[], int n, int *min, int *max)
{
    *min = a[0];                     /* 先假设第一个既最小也最大 */
    *max = a[0];

    for (int i = 1; i < n; i++) {
        if (a[i] < *min) *min = a[i];   /* ⭐ 写进调用者的 lo */
        if (a[i] > *max) *max = a[i];   /* ⭐ 写进调用者的 hi */
    }
}

int main(void)
{
    int arr[6] = {5, 2, 9, 1, 7, 3};
    int lo, hi;
    minmax(arr, 6, &lo, &hi);        /* ⭐ 传地址 */
    printf("min=%d max=%d\n", lo, hi);   /* min=1 max=9 */
}
```

### 可视化

```
调用者 main:                被调用者 minmax:
lo [0x5000] = 垃圾   ←────  min  = 0x5000
hi [0x5004] = 垃圾   ←────  max  = 0x5004
                                  ↓
                    *min = 5  → 写到 0x5000 → lo = 5
                    *max = 5  → 写到 0x5004 → hi = 5
                    ... 循环后
                    lo = 1, hi = 9
```

### 三个常见错误

| 错误写法 | 后果 |
| --- | --- |
| `min = &a[i];` | ❌ 只改了**指针本身**，调用者的 lo 没变 |
| `min = a[i];` | ❌ **丢了 `*`**，只改局部变量 |
| `minmax(arr, 6, lo, hi);` | ❌ **忘传 `&`** → 编译报错（类型不符） |

### 为什么这个模式无处不在

```c
/* 标准库 */
gettimeofday(&tv, NULL);              /* 结果写进 tv */

/* Linux 内核风格 */
int foo(..., int *result);            /* 返回 0=成功，结果放 *result */
```

## 六、三个必踩的坑

| 坑 | 代码 | 后果 |
| --- | --- | --- |
| **野指针** | `int *p; *p = 10;` | 往垃圾地址写 → 崩溃 |
| **空指针解引用** | `int *p = NULL; *p = 1;` | 段错误 |
| **类型不匹配** | `int x; char *p = &x;` | 警告；解引用读错字节数 |

---

## 七、本课记住的 4 条

1. **`&x` 取地址，`*p` 解引用**；同一个 `*` 在声明和表达式里意思不同
2. **C 只有值传递** → 要改调用者的变量，必须传地址
3. ⭐ **`a[i]` == `*(a + i)`**，数组名就是首元素地址
4. **`p++` 前进一个元素（`sizeof(类型)` 字节），不是 1 字节**
