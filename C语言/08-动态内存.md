# C 语言 第 8 课（上）：动态内存

> 2026-11-17。**核心：栈是自动的、小的；堆是手动的、大的 —— 而"手动"就意味着责任。**

---

## 一、为什么需要 `malloc`

| | 栈（stack） | 堆（heap） |
| --- | --- | --- |
| 分配方式 | `int arr[100];` 自动 | `malloc(...)` **手动** |
| 大小 | **编译期确定**，几 MB 上限 | **运行期决定**，几 GB |
| 释放 | 函数返回自动 | **必须 `free`** |
| 速度 | 快 | 慢一些 |

```c
int arr[100];              /* 编译期就定死 100 */
int n = 用户输入;
malloc(n * sizeof(int));   /* 运行时才知道要多少 → 只能上堆 */
```

## 二、`malloc` 三步曲

```c
#include <stdlib.h>        /* ⭐ malloc / free / atoi 都在这里 */

int *p = malloc(n * sizeof(int));     /* ① 申请 */

if (p == NULL) {                      /* ⭐ 必须检查 */
    perror("malloc");
    return 1;
}

for (int i = 0; i < n; i++) p[i] = ...;   /* ② 用：和数组完全一样 */

free(p);                              /* ③ 归还 */
p = NULL;                             /* ⭐ 置空，防悬空指针 */
```

### 三个细节

| 细节 | 说明 |
| --- | --- |
| **`n * sizeof(int)`** 而不是 `n * 4` | `sizeof` 自动适配平台（第 2 课） |
| **不用强转** | C 允许 `void *` 自动转任意指针；强转反而会掩盖"忘 include"的错误 |
| **`free(p); p = NULL;`** | free 之后指针悬空，置空防误用 |

**实测**：`malloc(5 * sizeof(int))` → 打印 `p[0..4] = 0,10,20,30,40` ✅

## 三、⛔ 三个致命坑（全部实测）

### 坑 1：内存泄漏（忘了 `free`）

```c
void leak(void) {
    int *p = malloc(100 * sizeof(int));
    /* 忘了 free */
}   /* 函数返回，p 没了，但内存还在 */
```

**实测 ASan 报告**（`dyn_leak.c` 注释掉 free）：
```
==9512==ERROR: LeakSanitizer: detected memory leaks

Direct leak of 20 byte(s) in 1 object(s) allocated from:
    #0 ... in malloc
    #1 ... in main /home/cxh/c-lab/07-malloc/dyn_leak.c:9    ← ⭐ 分配的那一行
    #2 ... __libc_start_call_main
    #3 ... _start

SUMMARY: AddressSanitizer: 20 byte(s) leaked in 1 allocation(s).
```

- **20 字节** = 5 个 int ✅
- **精确指到 `dyn_leak.c:9`**（malloc 那行）

**特征**：程序越跑内存越大，最后被 OOM 杀掉。

### 坑 2：⭐ use-after-free（用已释放的内存）

```c
int *p = malloc(10 * sizeof(int));
free(p);
p[0] = 999;              /* ⚠️ 那块内存已经还给系统了 */
```

**两道防线都开火**：

**① 编译期（`-Wall` 静态检查）**
```
dyn_leak.c:27:10: warning: pointer 'p' used after 'free' [-Wuse-after-free]
   27 |     p[0] = 999;
      |     ^~~~~~
dyn_leak.c:26:5: note: call to 'free' here
   26 |     free(p);
```

**② 运行期（ASan）**
```
ERROR: AddressSanitizer: heap-use-after-free on address 0x503000000040
WRITE of size 4 at 0x503000000040 thread T0
    #0 ... in main dyn_leak.c:27              ← 写在第 27 行

0x503000000040 is located 0 bytes inside of 20-byte region
freed by thread T0 here:
    #0 ... in free
    #1 ... in main dyn_leak.c:26              ← ⭐ 在第 26 行被 free

previously allocated by thread T0 here:
    #0 ... in malloc
    #1 ... in main dyn_leak.c:9               ← ⭐ 最初在第 9 行 malloc
```

**Shadow bytes**：
```
=>0x503000000000: fa fa 00 00 00 00 fa fa fa[fd]fd fd fd fa fa fa
                                            ↑ fd = Freed heap region
```
- `00` = 可用（当年 malloc 出来的 20 字节）
- **`fd` = 已释放的堆区** ← 你写的就是这里
- `fa` = 堆的左/右红区

> ## 🔑 ASan 一次给出**三条调用链**
> **写在哪（27行）→ free 在哪（26行）→ malloc 在哪（9行）**
> 这就是它比 `printf` 调试强的地方：**它记得这块内存的全部历史。**

### 坑 3：`free` 后不置空

```c
free(p);
/* ... 很多代码 ... */
if (p) p[0] = 1;         /* ⚠️ p 不是 NULL！它是悬空指针 */
```

**所以 `free(p); p = NULL;` 要成对写。**

## 四、`atoi`：字符串转数字

```c
#include <stdlib.h>

int n = atoi("123");      /* → 123 */
int m = atoi("abc");      /* → 0（没有错误提示！） */
```

> ⚠️ **`atoi` 的缺陷**：无法区分"字符串是 0"和"字符串不合法"。
> **生产代码用 `strtol`**：`long v = strtol(s, &end, 10); if (*end != '\0') 报错;`
> 现在先用 `atoi` 够用。

## 五、完整示例：动态数组求和

```c
#include <stdio.h>
#include <stdlib.h>

int main(int argc, char *argv[])
{
    if (argc != 2) {
        fprintf(stderr, "用法: %s <数字>\n", argv[0]);
        return 1;
    }

    int n = atoi(argv[1]);

    if (n <= 0) { printf("总和 = 0\n"); return 0; }

    int *p = malloc(n * sizeof(int));
    if (p == NULL) { perror("malloc"); return 1; }

    for (int i = 0; i < n; i++) p[i] = i + 1;      /* 填 1..n */

    long sum = 0;                                   /* ⭐ long 防求和溢出 */
    for (int i = 0; i < n; i++) {
        sum += p[i];
        printf(i ? " + %d" : "%d", p[i]);
    }
    printf(" = %ld\n", sum);

    free(p);
    p = NULL;
    return 0;
}
```

**实测**：`./dyn_arr 5` → `1 + 2 + 3 + 4 + 5 = 15`

## 六、本课记住的 5 条

1. **栈自动/小/快；堆手动/大/慢** —— 手动就意味着责任
2. **`malloc` 后必须查 `NULL`**，**`free` 必须调**
3. **`free(p); p = NULL;`** 成对写
4. ⭐ **ASan 能同时抓泄漏和 use-after-free，并给出完整调用链**
5. **`sizeof` 算大小，别写死数字**
