# 第一部分 入门概述（001–004 集）

## 001 课程内容介绍 / 002 应用领域

**要点**
- 课程分七部分：基础篇、实操篇、高级篇、Java 定制篇、大数据定制篇、Python 定制篇、企业面试题。
- Linux 的应用领域：服务器（绝对主力）、嵌入式（路由器、机顶盒）、移动端（Android 内核）、云计算/K8s、大数据集群。

**自测**：为什么说“服务器领域 Linux 是绝对主流”？→ 免费、开源、稳定、可裁剪、生态完整。

## 003 Linux 概述

**要点**
- Linux 是**内核**（kernel），不是完整操作系统。我们用的“Linux 系统”= 内核 + GNU 工具 + 桌面环境 + 包管理器，称为**发行版**（distribution）。
- 常见发行版：RedHat/CentOS（RHEL 系）、Ubuntu/Debian、SUSE、Fedora、Rocky/AlmaLinux。
- 内核版本号形如 `7.0.0-38-generic`：主版本.次版本.修订号-编译号，`-generic` 是 Ubuntu 通用内核标记。

```bash
uname -a        # 看内核版本（一切系统都通用）
uname -r        # 只看内核版本号
cat /etc/os-release   # 看发行版信息（Ubuntu 上有，CentOS 7 是 /etc/redhat-release）
```

**自测**：Linux 和发行版什么关系？→ 内核 vs 打包好的整套系统。

## 004 Linux 与 Unix

**要点**
- Unix 是 1970 年代贝尔实验室的商业操作系统，Linux 是 1991 年 Linus 写的**类 Unix** 内核（遵循 POSIX 标准，命令风格一致）。
- 所以 Unix 上的东西（shell、管道、权限模型）在 Linux 上都通用。

**自测**：为什么 Linux 命令和 macOS（Unix 系）那么像？→ 都遵循 POSIX 与 Unix 传统。

# 第二部分 虚拟机环境（005–011 集）

## 005 VMware 安装（课程用 15.5，你用 17.5.2）

**要点**：VMware Workstation 是**宿主机（host）**上的软件，里面跑的虚拟机叫**客户机（guest）**。

| 概念 | 你的情况 |
| --- | --- |
| 宿主机 | Windows，VMware 装在 `D:\VMware` |
| 客户机 | Ubuntu 24.04.5，8 GB 内存 / 4 核 / 60 GB 磁盘 |
| 配置文件 | `D:\VMs\Ubuntu-24.04\Ubuntu-24.04.vmx`（文本文件，可直接编辑） |

**记忆点**：`.vmx` 是**配置**，`.vmdk` 是**虚拟磁盘**（数据和系统都在这）。

## 006 装系统与手动分区 ★

**课程做法（CentOS 7.6）**

| 挂载点 | 大小 | 说明 |
| --- | --- | --- |
| `/boot` | 1 GB（有的写 200 MB） | 内核和启动文件，**必须独立分区** |
| `swap` | 2 GB（一般设为内存的 1–2 倍） | 交换分区，内存不够时当“虚拟内存” |
| `/` | 剩余全部 | 根分区 |

**你的 Ubuntu 实际情况（自动分区）**

| 设备 | 大小 | 挂载点 | 文件系统 |
| --- | --- | --- | --- |
| `/dev/sda1` | 1 GB | `/boot/efi` | vfat（EFI 启动必须，老 BIOS+CentOS 没有这个） |
| `/dev/sda2` | 约 59 GB | `/` | ext4 |
| `/swap.img` | 4 GiB | swap | **一个文件，不是分区** |

```bash
lsblk                       # 看磁盘和分区结构（比 fdisk -l 更直观）
df -h                       # 看各分区用了多少
swapon --show               # 看 swap 情况
free -h                     # 看内存 + swap
```

**CentOS → Ubuntu 三个差异**
1. EFI 固件需要 `/boot/efi`（FAT32），CentOS 那个年代多用 BIOS。
2. Ubuntu 默认用 **ext4**，CentOS 7 默认 **XFS**。
3. Ubuntu 桌面版默认用 **swap 文件**（`/swap.img`），CentOS 用 swap **分区**。

**自测**：/boot 为什么必须单独分？→ 内核和 GRUB 需要在开机早期被读取，不能被加密/LVM/损坏的根分区拖累。

## 007 网络连接三种方式 ★★

| 模式 | 虚拟机 IP 来源 | 能否上网 | 宿主机能否访问虚拟机 | 局域网其他机器能否访问 | 特点 |
| --- | --- | --- | --- | --- | --- |
| **桥接（Bridged）** | 和宿主机同网段的真实 IP | ✅ | ✅ | ✅ | 像局域网里一台独立电脑，会**占用路由器 IP** |
| **NAT** | VMware 虚拟网段（你的 `192.168.139.x`） | ✅ 通过宿主机转发 | ✅ | ❌ | **最安全**，不占外部 IP，开发常用 |
| **仅主机（Host-Only）** | 虚拟网段 | ❌ | ✅ | ❌ | 只能宿主机和虚拟机互访，适合内网实验 |

**你的情况**：NAT（VMnet8），虚拟机 `192.168.139.129`，宿主机侧网关/宿主地址 `192.168.139.1`。

```bash
ip addr          # 看 IP（Ubuntu 推荐）
ifconfig         # 老命令，需装 net-tools
ip route         # 看默认网关
cat /etc/resolv.conf   # 看 DNS
```

**自测**：为什么 SSH 登录后 `who` 显示来源是 `192.168.139.1`？→ 这是宿主机在 VMnet8 上的地址，NAT 转发后 SSH 看到的就是它。

## 008 虚拟机克隆

**要点**：克隆 = 复制一台完整的新虚拟机。

| 类型 | 特点 |
| --- | --- |
| **完整克隆** | 完全独立，占双倍空间，可单独使用 |
| **链接克隆** | 依赖原虚拟机磁盘，省空间，原机删了它就跑不了 |

**克隆完必做三件事**（否则两台机器 IP/主机名冲突）：
```bash
hostnamectl set-hostname 新名字          # 改主机名
cat /etc/machine-id                      # 检查 machine-id
sudo rm /etc/machine-id && sudo systemd-machine-id-setup   # 重新生成（Ubuntu）
```
IP 冲突：改网卡配置（Ubuntu 用 netplan，第 65 集讲）。

## 009 虚拟机快照 ★

**要点**：快照 = 给虚拟机“存档”，出问题一键回滚。做危险操作前必须拍。

VMware 菜单：`虚拟机 → 快照 → 拍摄快照 / 快照管理器`
- 拍快照很快，恢复也很快，但**会占磁盘空间**，别拍太多、定期合并。
- 你的工作习惯：**改配置文件、装驱动、试内核参数之前先拍一张。**

## 010 虚拟机迁移与删除

- **迁移**：把整个虚拟机目录（`.vmx` + `.vmdk`）拷走，在新机器上用 VMware「打开」即可。注意 CPU 特性差异可能要求重新生成配置文件。
- **删除**：VMware 里「从磁盘删除」会**真的删掉虚拟磁盘文件**，不可恢复 —— 先确认里面没重要东西。

## 011 VMware Tools（你在 Ubuntu 用的是 open-vm-tools）

**课程做法**：CentOS 挂载 VMwareTools 的 ISO，解压 `tar.gz`，跑 `vmware-install.pl`。

**你的做法（Ubuntu 官方推荐）**：
```bash
sudo apt install -y open-vm-tools-desktop
sudo reboot
```

**装了有什么用**：窗口自适应大小、宿主机↔虚拟机复制粘贴、拖拽传文件、共享文件夹、时间同步。**你已经装好并重启过，这些功能都生效了。**

**自测**：为什么 Ubuntu 不用装 VMware 官方 Tools？→ Ubuntu 自带开源实现 `open-vm-tools`，官方也已推荐它。

# 第三部分 目录结构与远程登录（012–015 集）

## 012 / 013 目录结构 ★★

`ls -l /` 输出的一行怎么读：

```
drwxr-xr-x  2 root root  4096 10月 20 16:23 boot
│└─┬─┘└┬┘ └┬┘  │    │     │        └ 名字
│  │   │   │   │    │     └ 最后修改时间
│  │   │   │   │    └ 大小（目录固定 4096）
│  │   │   │   └ 所属组
│  │   │   └ 硬链接数（目录 = 子目录数 + 2）
│  │   └ 其他人权限 / 属组权限 / 属主权限
└ 类型：d 目录、- 普通文件、l 软链接
```

**核心目录表**

| 目录 | 作用 | 你的机器上的注意点 |
| --- | --- | --- |
| `/bin` → `/usr/bin` | 基本命令 | 是**软链接** |
| `/sbin` → `/usr/sbin` | 管理员命令 | 同上 |
| `/boot` | 内核、GRUB | 你还有 `/boot/efi` |
| `/etc` | 所有配置文件 | 源在 `/etc/apt/`，**不是** `/etc/yum.repos.d/` |
| `/home` | 普通用户家目录 | 你在 `/home/cxh` |
| `/root` | root 家目录 | 权限 700，普通用户进不去 |
| `/var` | 常变数据、日志、网站 | 日志是 `/var/log/syslog`，**不是** `/var/log/messages` |
| `/usr` | 程序、库、文档 | 占磁盘最多的目录之一 |
| `/opt` | 额外安装的软件 | Tomcat/IDEA 这类解压式软件放这 |
| `/tmp` | 临时文件 | 权限末尾 `t` = 粘滞位，重启会清 |
| `/proc` `/sys` | 内核虚拟文件系统 | **显示大小 0 是正常的** |
| `/dev` | 设备文件 | `/dev/sda` 就是你的硬盘 |
| `/media` `/mnt` | 挂载点 | 手动挂载习惯用 `/mnt` |
| `/snap` | Ubuntu 独有 | CentOS 没有，不用管 |
| `/lost+found` | ext4 修复残留 | 不用管 |

**Ubuntu 独有的三个“看着奇怪”的东西**
1. `bin.usr-is-merged`、`sbin.usr-is-merged`、`lib.usr-is-merged` —— usr 合并后的**占位标记**，别删。
2. `/snap` —— snap 包目录。
3. `/swap.img` —— 4 GiB 的**交换文件**（对应课程的 swap 分区）。

**自测**
- `/etc` 和 `/var` 的区别？→ 前者是**配置**（人改的、很少变），后者是**运行时数据**（程序自己写的、经常变）。
- 为什么 `/proc` 大小是 0？→ 它在内存里，不占磁盘。

## 014 远程登录 ★★

**原理**：SSH（Secure Shell），默认端口 **22**，传输全程加密。需要在目标机装 **openssh-server**（Ubuntu 默认没装，CentOS 默认装了，这是重要差异）。

**课程做法**：装 Xshell → 输入 IP → 连接 → 输账号密码

**你的做法（零安装）**：
```powershell
# Windows PowerShell
ssh cxh@192.168.139.100
```
> ⚠️ 本笔记写于 10-21，当时 IP 还是 DHCP 的 `.129`；**10-29 起已改成静态 `192.168.139.100`**，下面所有 `.129` 的示例请自行替换。
> IP 又变了就先 `ssh-keygen -R 192.168.139.100` 清旧指纹，再用 `hostname -I` 查新地址。
第一次会问指纹 → 输 **`yes`** → 输密码（**屏幕上不显示任何字符，正常**）。

**关键命令**
```bash
who            # 谁登录了（seat0=登录界面, tty2=本地, pts/1=远程）
w              # 谁登录了 + 在干什么 + CPU + 负载
who am i       # 只看我自己这个会话（能看出 tty 还是 pts）
users          # 只列用户名
last           # 历史登录记录
lastb          # 失败登录记录（sudo）
exit / logout / Ctrl+D   # 断开
```

**记住**：`tty` = 本地登录，`pts` = 远程登录；`$` = 普通用户，`#` = root。

**自测**：SSH 登录日志在哪？→ CentOS `/var/log/secure`，Ubuntu `/var/log/auth.log`（两者都能用 `journalctl -u ssh`）。

## 015 远程传文件 ★

**课程做法**：Xftp（走 SFTP，端口 22）

**你的三种做法**

```powershell
# ① Windows → 虚拟机（在 PowerShell 里跑）
scp "C:\Users\cxh\Desktop\test.txt" cxh@192.168.139.129:~/

# ② 虚拟机 → Windows
scp cxh@192.168.139.129:~/from-ubuntu.txt "C:\Users\cxh\Desktop\"

# ③ 整个目录（加 -r）
scp -r 本地目录 cxh@192.168.139.129:~/
```

**格式记忆**：`scp 源 目标`；远程路径写成 `用户@IP:路径`，`:` 后面省略就是家目录 `~`。

**其他方式**：VMware 直接拖拽（已装 open-vm-tools）、PowerShell 内置 `sftp`、图形工具 WinSCP（协议选 SFTP）。

**自测**：SFTP 和 FTP 的区别？→ SFTP 走 22 端口、全程加密；FTP 走 21 端口、明文传密码。

## 016–018 vim ★★★（最容易卡的地方）

**三种模式**：`正常模式`（默认，快捷键都在这）—`i/a/o`→ `插入模式`（能打字）—`Esc`→ `正常模式` —`:` 或 `/`→ `命令行模式`

**三板斧**：`vim 文件` → 按 `i` → 打字 → `Esc` → `:wq` 回车

| 必背 | 键 |
| --- | --- |
| 保存退出 | `:wq`；放弃修改退出 `:q!` |
| 跳首尾 | `gg` / `G` |
| 删行 / 复制行 / 粘贴 / 撤销 | `dd` / `yy` / `p` / `u` |
| 全文替换 | `:%s/旧/新/g` |
| 查找 | `/关键字`，`n` 下一个 |
| 显示行号 | `:set nu` |

**卡住就**：连按两下 `Esc`，再 `:q!` 回车。

**Ubuntu 差异**：你装了完整 vim，方向键和退格正常，不用像课程里那样改配置。

## 019 关机重启 ★

```bash
sync                    # 先把内存数据刷盘（好习惯）
shutdown -h now         # 立刻关机
shutdown -h 1           # 1 分钟后关机（会广播通知）
shutdown -c             # 取消关机
shutdown -r now         # 立刻重启
halt / poweroff         # 关机
reboot                  # 重启
init 0 / init 6         # 老写法：关机 / 重启（走 systemd 兼容层）
```

**要点**
- Linux 是多用户系统，所以用 `shutdown` **通知 + 延迟**，而不是直接断电。
- 精确等价：`init 0` → `systemctl isolate poweroff.target`；`init 6` → `systemctl isolate reboot.target`。
- 在 SSH 里 `reboot` 会**断开连接，属正常**；重启后 IP 可能变，用 `hostname -I` 重查。

## 020 登录注销 ★★

```bash
logout          # 注销（SSH 会话有效）
exit            # 退出当前一层 shell；Ctrl+D 同效
su 用户名        # 切换用户，保留原环境
su - 用户名      # 切换用户 + 加载完整环境（推荐，注意横杠）
sudo -i         # Ubuntu 切 root 的正确姿势（完整环境）
sudo -s         # 切 root，保留环境
sudo -u 用户 命令 # 以指定用户身份执行一条命令
```

**提示符**：`cxh@主机:~$` 普通用户；`root@主机:~#` 超级用户（`#` 要格外小心）。

**⚠️ 最大的 CentOS→Ubuntu 差异**

| | CentOS 7.6 | Ubuntu 24.04 |
| --- | --- | --- |
| root 密码 | 装系统时强制设置 | **默认锁定**（没有密码） |
| `su - root` | ✅ 可用 | ❌ `su: 认证失败` |
| 提权方式 | `su -` 或 `sudo` | **`sudo -i` / `sudo 命令`** |
| 验证 root 被锁 | — | `sudo passwd -S root` 输出含 `L` |

**自测**：`sudo -i` 和 `sudo -s` 区别？→ 前者加载 root 的完整登录环境（家目录变 `/root`、PATH 重载），后者保留你当前环境。
