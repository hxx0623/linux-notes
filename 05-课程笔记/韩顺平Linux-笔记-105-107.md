## 二、【课件】17.13.2 原始代码

```bash
#!/bin/bash
BACKUP=/data/backup/db
DATETIME=$(date +%Y-%m-%d_%H%M%S)
echo $DATETIME
HOST=localhost
DB_USER=root
DB_PW=xxxxxx
DATABASE=testdb

# 创建备份目录，如果不存在就创建
[ ! -d "${BACKUP}/${DATETIME}" ] && mkdir -p "${BACKUP}/${DATETIME}"

# 备份数据库
mysqldump -u${DB_USER} -p${DB_PW} --host=${HOST} -q -R --databases ${DATABASE} \
    | gzip > ${BACKUP}/${DATETIME}/$DATETIME.sql.gz

# 将文件处理成 tar.gz
cd ${BACKUP}
tar -zcvf $DATETIME.tar.gz ${DATETIME}

# 删除对应的备份目录
rm -rf ${BACKUP}/${DATETIME}

# 删除 10 天前的备份文件
find ${BACKUP} -atime +10 -name "*.tar.gz" -exec rm -rf {} \;

echo "备份数据库${DATABASE}成功~"
```

### 关键点逐条讲

| 片段 | 要点 |
| --- | --- |
| 变量集中在开头 | 改备份目录/数据库只改前几行 |
| `$(date +%Y-%m-%d_%H%M%S)` | → `2026-11-04_144209` |
| `[ ! -d 路径 ] && mkdir -p` | **短路**：目录不存在才创建 |
| `mysqldump \| gzip > x.sql.gz` | **管道压缩**，省掉巨大的中间文件 |
| `cd ${BACKUP}` + `tar` | **tar 打包的相对路径基于当前目录** |
| `rm -rf 临时目录` | 打完包就不需要了 |
| `find -exec rm {} \;` | `{}` = 找到的文件，`\;` = exec 结束标记 |

### 六个值得改进的地方

| # | 问题 | 后果 |
| --- | --- | --- |
| 1 | 密码明文写脚本 | 谁读脚本都看到密码 |
| 2 | **没有 `set -e`** | 备份失败也继续，**产出"空备份"还报成功** |
| 3 | `-atime` 是**访问**时间 | 备份文件被读过就刷新，**永远删不掉** |
| 4 | 变量多处没加引号 | 路径含空格就崩 |
| 5 | 不检查命令是否存在 | 命令缺失也"成功" |
| 6 | 没有日志 | 定时任务失败无从追溯 |

**最危险的是第 2 条**：**你以为有备份，真出事时打不开。**

## 三、改造：能真跑的版本

### 改造 1：用 `tar -C` 打成**单层**

```bash
tar -zcf "${TARGET}" -C "$(dirname "${SRC}")" "$(basename "${SRC}")"
```

| 部分 | 作用 |
| --- | --- |
| `-C 目录` | 先切到该目录再打包（结束后切回） |
| `$(dirname "${SRC}")` | `/home/cxh` |
| `$(basename "${SRC}")` | `ztest` |

**结果**：包内只有 `ztest/...`，解压出来是干净目录，**不用两层解压**。

> 这里正好用上 103 集的 `basename` / `dirname`。
>
> **反例**：直接 `tar -zcf x.tar.gz /home/cxh/ztest` → tar 会警告 `从成员名中删除开头的"/"`，包内变成 `home/cxh/ztest/...`。

### 改造 2：日志（`tee -a`）

```bash
LOG="${BACKUP}/backup.log"
log() { echo "[$(date '+%F %T')] $*" | tee -a "$LOG"; }
```

| 写法 | 屏幕 | 文件 |
| --- | --- | --- |
| `>> 文件` | ❌ | ✅ |
| **`\| tee -a 文件`** | ✅ | ✅ |

### 改造 3：`set -euo pipefail`

| 参数 | 作用 |
| --- | --- |
| `-e` | 命令失败立即退出 |
| `-u` | 用未定义变量就报错（防拼写） |
| **`-o pipefail`** | **管道任一环失败都算失败**（`mysqldump \| gzip` 才能发现问题） |

### 改造 4：`rm -rf` 加 `${VAR:?}`

```bash
rm -rf "${BACKUP:?}/${DATETIME:?}"
```

| 写法 | 变量为空时 |
| --- | --- |
| `${VAR}` | 展开成空 → **可能 `rm -rf /`** |
| **`${VAR:?}`** | **报错退出** |

**shellcheck 的 SC2115 警告就是这个。**

### 改造 5：打包后校验

```bash
tar -tzf "${TARGET}" >/dev/null || die "备份文件校验失败"
```

`tar -tzf` 会把整个包完整读一遍 → 能读完说明压缩流完整。挡掉"磁盘满导致备份被截断"。

### 完整脚本（正经版）

```bash
#!/bin/bash
set -euo pipefail

# ===== 配置区 =====
BACKUP=/home/cxh/backup
SRC=/home/cxh/ztest
KEEP_DAYS=10
LOG="${BACKUP}/backup.log"

# ===== 变量 =====
DATETIME=$(date +%Y-%m-%d_%H%M%S)
TARGET="${BACKUP}/${DATETIME}.tar.gz"

# ===== 工具函数 =====
log() { echo "[$(date '+%F %T')] $*" | tee -a "${LOG}"; }
die() { log "错误: $*"; exit 1; }

# ===== 前置检查 =====
mkdir -p "${BACKUP:?}"
[ -d "${SRC:?}" ]          || die "源目录 ${SRC} 不存在"
command -v tar >/dev/null  || die "缺少 tar 命令"
[ -f "${TARGET}" ]         && die "同名备份已存在: ${TARGET}"

# ===== 打包（单层）=====
log "开始备份 ${SRC} -> ${TARGET}"
tar -zcf "${TARGET}" -C "$(dirname "${SRC}")" "$(basename "${SRC}")" || die "打包失败"

# ===== 校验 =====
tar -tzf "${TARGET}" >/dev/null || die "备份文件校验失败"
SIZE=$(du -h "${TARGET}" | cut -f1)
log "备份完成: ${TARGET} (${SIZE})"

# ===== 清理旧备份 =====
DELETED=$(find "${BACKUP}" -maxdepth 1 -name "*.tar.gz" \
          -mtime +${KEEP_DAYS} -print -delete | wc -l)
[ "${DELETED}" -gt 0 ] && log "已清理 ${DELETED} 个 ${KEEP_DAYS} 天前的备份"

log "全部完成"
exit 0
```

### 🔑 恢复演练（最重要的一步）

**备份的价值 = 能恢复。没演练过的备份不算备份。**

```bash
rm -rf /tmp/restore && mkdir -p /tmp/restore
tar -xzf ~/backup/2026-11-04_160431.tar.gz -C /tmp/restore
diff -r ~/ztest /tmp/restore/ztest && echo "✅ 恢复内容与源完全一致"
```

| `diff -r` 输出 | 含义 |
| --- | --- |
| **无输出** | 完全一致 |
| `<` `>` 行 | 有差异 |
| `Only in ...` | 少文件/多文件 |

### 挂 crontab

```cron
0 2 * * * /home/cxh/shcode/backup.sh
```

- 脚本自己用 `tee` 写日志，cron 里不用重定向
- cron 的 `PATH` 短，`tar date du find` 都在 `/usr/bin`（默认 PATH 内），所以能跑；**自己装的程序要写全路径**
- 快速验证：临时改成 `*/2 * * * *`，等 3 分钟看日志，再改回

## 四、tar 三字母口诀（查看备份必备）

```
tar -[z] [动作] f [文件]

z = gzip 压缩（处理 .tar.gz 必须有）
动作：
  -c  新建压缩包（create）
  -t  查看清单（list）
  -x  解压（extract）
```

| 想干什么 | 命令 |
| --- | --- |
| **看清单** | `tar -tzf 包.tar.gz` |
| 解压到当前目录 | `tar -xzf 包.tar.gz` |
| **解压到指定目录** | `tar -xzf 包.tar.gz -C /tmp/xx` |
| 打包 | `tar -zcf 包.tar.gz 目录` |
| **单个文件输出到屏幕（不解压）** | `tar -xzOf 包.tar.gz 路径` |

**⚠️ `.tar.gz` 是二进制，`cat` 出来是乱码 —— 正常，不是文件坏了。**

### 速查卡

**变量**

| 写法 | 作用 |
| --- | --- |
| `A=100` | 定义（等号两边**不能有空格**） |
| `$A` / `${A}` | 取值（后跟字母时必须花括号） |
| `unset A` / `readonly B=2` | 删除 / 只读 |
| `export A` | 变成环境变量 |
| `A=$(cmd)` | 命令结果赋值 |
| `${A:-默认}` | 空值时用默认 |
| **`${A:?错误}`** | **空值时报错退出**（`rm -rf` 必用） |
| `${A%.txt}` / `${A##*/}` | 去后缀 / 取文件名 |

**引号**

| 写法 | 展开 | 空格 |
| --- | --- | --- |
| `$A` | ✅ | 会拆成多参数 |
| **`"$A"`** | ✅ | 保留（默认用它） |
| `'$A'` | ❌ | 保留 |

**参数与预定义**

`$0` 脚本名 · `$1-$9`/`${10}` 参数 · `$#` 个数 · `"$@"` 每个独立（永远用它）· `"$*"` 合一 · `$$` PID · `$!` 后台 PID · `$?` 退出码

**判断**

`[ "$a" = "$b" ]` · `-eq -ne -lt -le -gt -ge` · `-r -w -x` · `-f -d -e`
**绝不用 `>` `<`（是重定向）**

**流程**

```bash
if [ 条件 ]; then ... elif ... else ... fi
case $1 in "a") ... ;; *) ... ;; esac
for i in {1..10..2}; do ...; done
for ((i=1;i<=10;i++)); do ...; done
while [ 条件 ]; do ...; done
```

**函数**

```bash
f() { local x=$1; echo $((x+$2)); return 0; }
r=$(f 3 5)          # 捕获「返回值」（用 echo）
f 1 2 && echo ok    # 用「返回码」判断（return 只能 0-255）
```

### 脚本骨架模板

```bash
#!/bin/bash
set -euo pipefail

# ===== 配置区 =====
XXX=/path/to/xxx

# ===== 工具函数 =====
log()   { echo "[$(date '+%F %T')] $*"; }
die()   { echo "[$(date '+%F %T')] 错误: $*" >&2; exit 1; }
usage() { echo "用法: $(basename "$0") <参数>"; exit 2; }

# ===== 前置检查 =====
[ $# -ge 1 ] || usage
[ -d "$1" ]  || die "目录不存在: $1"

# ===== 主流程 =====
main() {
    log "开始"
    ...
    log "完成"
}

main "$@"
```

**`main "$@"` 是专业脚本的标志** —— 参数能传进函数，脚本还能被 `source` 只加载函数。

### 五个"坑家族"

| 家族 | 表现 | 记法 |
| --- | --- | --- |
| **空格** | `A = 1`、`[1=1]`、`while[` | shell 里空格就是语法 |
| **引号** | `$*` vs `$@`、单双引号 | 变量一律加双引号 |
| **子 shell** | 管道右边、`$( )`、`bash 脚本` | 子 shell 里的改动带不出来 |
| **整数** | `1/2=0`、`return 300`→44 | 只有整数，return 只有 8 位 |
| **展开时机** | `*` 被 shell 先展开、cron 里的 `%` | shell 先处理，命令后收到 |

## 六、自测题

1. `set -euo pipefail` 三个参数的作用？
2. `tar -C 目录` 是干什么的？为什么能保证包内路径干净？
3. 打包完为什么还要 `tar -tzf 包 >/dev/null`？
4. 怎么证明一个备份是真能用的？
5. `A = 100` 和 `A=100` 有什么区别？
6. `"$@"` 和 `"$*"` 在 `for` 里循环次数一样吗？
7. `[ 2 > 1 ]` 会发生什么？
8. `cat f | while read` 里的变量为什么循环后消失？

<details>
<summary>答案</summary>

1. `-e` 失败即退、`-u` 未定义变量报错、**`-o pipefail` 管道任一环失败都算失败**
2. **切到该目录再打包**；用 `basename` 作相对路径，包内就不带 `/home/cxh` 前缀，解压出来是干净目录
3. **验证压缩流完整**（能完整读完说明没被截断），挡掉"磁盘满导致备份损坏"
4. **解压 + `diff -r` 和源目录逐字节比对**（没做过恢复演练的备份不算备份）
5. `A=100` 是赋值；`A = 100` 是**执行命令 A**（`=` 和 `100` 当参数）→ 未找到命令
6. **不一样**：`"$*"` 循环 1 次（合成一个），`"$@"` 循环 N 次
7. 解析成 `[ 2 ]`（非空为真）+ `> 1`（**重定向，创建文件 `1`**）
8. 管道右边是**子 shell**，变量改动随子 shell 消失 → 用 `while read ... done < f`
