## 一、【课件】17.8 运算符

### 三种写法

| 方式 | 例子 | 说明 |
| --- | --- | --- |
| **`$(( ))`** | `RES=$(((2+3)*4))` | ⭐ **首选**，可嵌套、bash 内建 |
| `$[ ]` | `RES=$[(2+3)*4]` | ⚠️ **bash 4.4 起已废弃**（课件当时推荐它，已过时） |
| `expr` | `expr 2 + 3` | 外部命令，坑最多 |

### `expr` 的三个坑

| 坑 | 现象 | 原因 |
| --- | --- | --- |
| **运算符两侧必须有空格** | `expr 2+3` → 输出 `2+3` | 整个 `2+3` 被当成一个字符串 |
| **乘号要转义 `\*`** | `expr 2 * 3` → 报错 | **shell 先把 `*` 展开成文件名列表**，expr 收到一堆参数 |
| 结果赋给变量要用 `$()` | `TEMP=$(expr 2 + 3)` | 不能直接 `TEMP=expr ...` |

> **`expr 2 * 3` 的本质**：shell 的通配符展开发生在“命令执行”之前 → expr 根本没看到 `*`。

### ⚠️ Shell 只支持整数

```bash
echo $((1/2))     # 0   ← 不是 0.5
echo $((7/2))     # 3   ← 截断，不四舍五入
echo $((7%2))     # 1
```

**要小数必须用 `bc` 或 `awk`：**

```bash
echo "scale=2; 7/2" | bc           # 3.50
awk 'BEGIN{printf "%.2f\n", 7/2}'  # 3.50
```

### `$(( ))` 的额外能力

```bash
a=10
echo $((a+1))        # 变量不用写 $
((a++))              # 自增，不带 $ 也能用
((a+=5))
echo $(( a > 10 ? 100 : 0 ))    # 三目运算
```

## 二、【课件】17.9 条件判断

### 基本语法

```bash
[ condition ]
```

**三条铁律：**

| 规则 | 正确 | 错误 |
| --- | --- | --- |
| `[` 后面有空格 | `[ 1 = 1 ]` | `[1 = 1]` |
| `]` 前面有空格 | `[ 1 = 1 ]` | `[ 1 = 1]` |
| 条件内部有空格 | `[ 1 = 1 ]` | `[ 1=1 ]` ← **陷阱：这是“非空字符串”为真，不是比较！** |

**为什么？因为 `[` 是一个命令**（`/usr/bin/[`，等价 `test`）。

```bash
type [            # [ 是 shell 内建
test 1 = 1        # 与 [ 1 = 1 ] 完全等价
```

### 返回值

| `$?` | 含义 |
| --- | --- |
| **0** | **true（条件成立）** |
| 非 0 | false |

### `&&` / `||` 组合

```bash
[ 条件 ] && echo OK || echo notok
```

| 符号 | 含义 |
| --- | --- |
| `&&` | 前面成功才执行后面 |
| `\|\|` | 前面失败才执行后面 |

### 四类判断条件（课件原文）

**① 字符串比较**

| 运算符 | 含义 |
| --- | --- |
| `=` | 相等（**必须加双引号**：`[ "$a" = "$b" ]`） |
| `!=` | 不等 |
| `-z` / `-n` | 长度为 0 / 不为 0 |

**② 整数比较（六个）**

| 运算符 | 含义 |
| --- | --- |
| `-eq` | 等于 |
| `-ne` | 不等于 |
| `-lt` | 小于 |
| `-le` | 小于等于 |
| `-gt` | 大于 |
| `-ge` | 大于等于 |

**⚠️ 绝对不能用 `>` `<` 比较整数：**

```bash
[ 2 > 1 ]      # ❌ 这不是比较！是「输出重定向到文件 1」
```

会被解析成 `[ 2 ]`（非空为真）+ `> 1`（创建文件）。**文件 1 真的会被创建。**

**③ 文件权限判断**

| 运算符 | 含义 |
| --- | --- |
| `-r` / `-w` / `-x` | 读 / 写 / 执行权限 |

**④ 文件类型判断**

| 运算符 | 含义 |
| --- | --- |
| `-f` | 存在且是**常规文件** |
| `-e` | **存在**（不管类型） |
| `-d` | 存在且是**目录** |

补充：`-s` 非空、`-L` 软链接、`-nt`/`-ot` 比新旧。

## 三、【课件】17.10.1 `if` 判断

```bash
if [ 条件 ]
then
    代码
fi

# 多分支
if [ 条件 ]
then
    代码
elif [ 条件 ]
then
    代码
else
    代码
fi
```

### 四个要点

| 要点 | 说明 |
| --- | --- |
| `then` 必须跟在 `if`/`elif` 后 | 换行或 `;` |
| 结尾 `fi` | `if` 倒写 |
| **`elif` 不是 `else if`** | shell 没有 `else if` |
| 一行写要加 `;` | `if [ x ]; then ...; fi`（`;` = 换行） |

### 课件案例：`ifCase.sh`（成绩判断）

```bash
#!/bin/bash
if [ $# -ne 1 ]
then
    echo "用法: $0 <分数>"
    exit 1
fi

if [ "$1" -ge 90 ]
then
    echo "优秀"
elif [ "$1" -ge 60 ]
then
    echo "及格了"
else
    echo "不及格"
fi
```

> ⚠️ 不传参数时 `[ $1 -ge 60 ]` 会报 `需要一元表达式` —— **所以要先检查 `$#`**。
> **写实用脚本的第一条规矩：先验证输入，再干活。**

### ⚠️ 实战踩坑：`elif` 忘了 `then`

```bash
elif [ "$1" -ge 60 ]
    echo "s"          # ← 少了 then
else
```

**报错指向 `else` 那一行**，而不是缺 `then` 的那一行 —— 因为 bash 把 `echo "s"` 当成了 elif 条件列表里的第二条命令，直到碰上 `else` 才发现 `then` 没出现。

> **教训：Shell 的语法报错，报错行往往不是出错行，往上看一两行。**

**两个检查手段：**

```bash
bash -n 脚本.sh        # 只做语法检查，不执行
shellcheck 脚本.sh     # 更严格，还会提示未加引号的变量等隐患
```

## 四、【课件】17.10.2 `case`

```bash
case $变量名 in
    "值1")
        程序1
        ;;
    "值2")
        程序2
        ;;
    *)
        默认程序
        ;;
esac
```

| 部分 | 说明 |
| --- | --- |
| `case $变量 in` | 开头 |
| `"值")` | 分支，**以右圆括号结束** |
| **`;;`** | **每个分支的结束符**（相当于 break） |
| `*)` | 默认分支（匹配一切） |
| `esac` | 结尾（`case` 倒写） |

**⚠️ 课件里那个 `）` 是全角括号**，抄进代码必须换成半角 `)`。

### 两个坑

| 坑 | 后果 |
| --- | --- |
| **忘写 `;;`** | **贯穿（fall through）**：会接着执行下一个分支的代码 |
| `*)` 放中间 | 它匹配一切，后面的分支成死代码 |

### 进阶匹配

```bash
case $1 in
    "start"|"begin")  echo "启动" ;;        # 多个值用 |
    [Yy]*)            echo "确认" ;;        # 通配符：y/Y 开头
    *)                echo "用法: $0 start|stop" ;;
esac
```

**`case` vs `if`：比大小、查文件 → `if`；同一变量多个取值 → `case`。**

## 五、【课件】17.10.3 `for`

### 语法 1：遍历式

```bash
for 变量 in 值1 值2 值3
do
    代码
done
```

### 课件案例：`$*` vs `$@` 的直观演示

```bash
#!/bin/bash
for i in "$*"; do echo "num is $i"; done
echo "----------"
for j in "$@"; do echo "num is $j"; done
```

```bash
./testFor1.sh 100 200 300
```

| 写法 | 循环次数 | 输出 |
| --- | --- | --- |
| `"$*"` | **1 次** | `num is 100 200 300` |
| `"$@"` | **3 次** | 分别输出三个 |

**只有一个参数时两者一样；超过一个才分家。**

### 语法 2：C 风格

```bash
for (( 初始值; 循环控制条件; 变量变化 ))
do
    代码
done
```

**⚠️ `for (( ))` 里的变量不加 `$`：**

```bash
for (( i=1; i<=100; i++ ))      # ✅
for (( $i=1; $i<=100; $i++ ))    # ❌
```

**执行顺序：初始值 → 判断 → 循环体 → `i++` → 再判断。**

### 课件案例：1 加到 100

```bash
#!/bin/bash
SUM=0
for (( i=1; i<=100; i++ ))
do
    SUM=$((SUM+i))
done
echo "1+2+...+100 = $SUM"
```

**累加三种写法：`SUM=$((SUM+i))` / `SUM=$[SUM+i]` / `((SUM+=i))`（最地道）**

### 常用遍历清单

| 遍历什么 | 写法 |
| --- | --- |
| **数字范围** | `for i in {1..10}` ⭐ |
| **带步长** | `for i in {1..10..2}` → 1 3 5 7 9 |
| **文件列表** | `for f in *.txt` |
| 命令输出 | `for u in $(cat list.txt)` |
| 脚本参数 | `for a in "$@"` |
| 数组 | `for x in "${arr[@]}"` |

### ⚠️ 通配符无匹配的坑

```bash
for f in *.txt; do echo "处理: $f"; done
# 没文件时输出：处理: *.txt      ← 字面量被当成文件处理！
```

**两种修法：**

```bash
[ -e "$f" ] || continue         # 循环里判断
shopt -s nullglob               # 或开启 nullglob
```

## 六、【课件】17.10.4 `while`

```bash
while [ 条件 ]
do
    代码
done
```

> 课件注意点：`while` 和 `[` 之间、条件与 `[` 之间都要有空格。

### 课件案例：1+..+n

```bash
#!/bin/bash
SUM=0
i=0
while [ $i -le $1 ]
do
    SUM=$((SUM+i))
    i=$((i+1))          # ⭐ 必须，否则死循环
done
echo "1+..+$1 = $SUM"
```

### ⚠️ 死循环

**`while` 不会自动改变条件，循环变量必须在体内变化。** 忘了 `i=$((i+1))` 就无限刷屏。

**三种防护：**

| 手段 | 说明 |
| --- | --- |
| 每写一个 while 问“谁会让我退出” | 习惯 |
| 加安全计数器 | `((n++)); [ $n -gt 1000 ] && break` |
| **`timeout 5 ./script.sh`** | 5 秒强杀，测试必备 |

### 故意写死循环（合法）

```bash
while true
do
    read -p "输入 exit 退出: " cmd
    [ "$cmd" = "exit" ] && break
done
```

`while :` 等价于 `while true`。

### 🔴 读文件的坑：管道 vs 重定向

```bash
COUNT=0
cat /etc/passwd | while read line; do COUNT=$((COUNT+1)); done
echo $COUNT        # 0  ❌

COUNT=0
while read line; do COUNT=$((COUNT+1)); done < /etc/passwd
echo $COUNT        # 好几行 ✅
```

**原因：管道 `|` 会为右边创建子 shell**，`while` 在子 shell 里跑，改的变量随子 shell 消失。

| 写法 | 在哪个 shell | 变量出来还在吗 |
| --- | --- | --- |
| `cat f \| while read` | **子 shell** | ❌ |
| **`while read ... done < f`** | 当前 shell | ✅ |

**最健壮的读文件写法：**

```bash
while IFS= read -r line; do
    echo "$line"
done < 文件
```

| 部分 | 作用 |
| --- | --- |
| `IFS=` | 不吃掉行首尾空格 |
| `-r` | 不把 `\` 当转义 |

## 七、【课件】17.11 `read`

```bash
read (选项) (参数)
```

| 选项 | 作用 |
| --- | --- |
| **`-p`** | 提示符 |
| **`-t`** | 等待秒数，超时不再等 |

| 参数 | 作用 |
| --- | --- |
| 变量名 | 存进这个变量（**不加 `$`**） |

### 课件案例

```bash
#!/bin/bash
read -p "请输入一个数NUM1=" NUM1
echo "你输入的NUM1=$NUM1"

read -t 10 -p "请输入一个数NUM2=" NUM2
echo "你输入的NUM2=$NUM2"
```

### 行为特点

| 特点 | 说明 |
| --- | --- |
| 读**一行**，回车才返回 | — |
| **变量名不加 `$`** | `read a` |
| 可一次读多个 | `read a b c`，按空白切 |
| 不写变量名 | 存进 `$REPLY` |

**多变量分配规则：**

```bash
read a b <<< "1 2 3 4"
# a=1  b="2 3 4"     ← 多出来的全给最后一个
```

### ⭐ `-t` 超时的返回值

```bash
read -t 5 -p "输入: " x
echo $?      # 超时 → 142
```

| 情况 | `$?` |
| --- | --- |
| 读到内容 | 0 |
| **超时** | **142** |
| EOF | 1 |

```bash
read -t 5 -p "输入: " x
if [ $? -ne 0 ]; then x="默认值"; fi
```

### 其他实用选项

| 选项 | 作用 |
| --- | --- |
| **`-s`** | **不回显 → 输密码** |
| **`-n 1`** | 读 1 字符，**不用回车** |
| `-r` | 不处理反斜杠 |
| `-a 数组` | 读进数组 |

## 八、【课件】17.12 函数

### 系统函数 `basename` —— 取最后 `/` 后面的部分

```bash
basename [pathname] [suffix]
```

```bash
basename /home/aaa/test.txt        # test.txt
basename /home/aaa/test.txt .txt   # test      ← 指定后缀会去掉
basename /a/b/c.txt .txt           # c
```

### 系统函数 `dirname` —— 取最后 `/` 前面的部分

```bash
dirname /home/aaa/test.txt         # /home/aaa
```

```
        /home/aaa/test.txt
dirname └────────┘            basename └──────┘
        /home/aaa                          test.txt
```

### 实战：脚本里取自己的名字和位置

```bash
SCRIPT_NAME=$(basename "$0")
SCRIPT_DIR=$(dirname "$(readlink -f "$0")")     # readlink -f 转绝对路径
echo "[$SCRIPT_NAME] 位于 $SCRIPT_DIR"
```

**为什么 `readlink -f`**：`$0` 可能是 `./func.sh`，直接 `dirname` 得到 `.`（没用的相对路径）。

### 自定义函数

```bash
[function] funname [()]
{
    Action;
    [return int;]
}
```

| 元素 | 能否省 |
| --- | --- |
| `function` | ✅ 能 |
| `()` | ✅ 能（建议保留） |
| `{}` | ❌ 不能 |
| `return int` | ✅ 可选 |

**调用：直接写函数名 + 参数。**

### ⚠️ 课件案例的写法问题

课件里：

```bash
function getSum(){
    SUM=$[$n1+$n2]        # ← 用全局变量 n1 n2
    echo "和是=$SUM"
}
read -p "..." n1
read -p "..." n2
getSum $n1 $n2            # ← 传了参数却没用 $1 $2
```

**能跑但不可复用** —— 函数只认那两个特定变量名。

**正确写法：**

```bash
getSum() {
    echo $(( $1 + $2 ))      # ⭐ 用位置参数
}
getSum 100 200               # 300
```

> **shell 函数没有“参数列表”** —— 和脚本一样用 `$1 $2` 拿参数，`$#` 是参数个数。

### 🔴 `return` 只能返回 0–255

```bash
getSum() { return $(( $1 + $2 )); }
getSum 100 200
echo $?        # 44 ！  300 mod 256 = 44
```

| 想返回什么 | 用什么 |
| --- | --- |
| 成功/失败（0–255） | `return N` + `$?` |
| **字符串/大数字/路径** | **`echo` + `$( )` 捕获** |

```bash
getSum() { echo $(( $1 + $2 )); }
result=$(getSum 100 200)      # 300 ✅
```

### `local`：函数内变量

```bash
f() {
    x=1            # ❌ 全局！会污染外部
    local y=2      # ✅ 只在函数内有效
}
```

**shell 函数里的变量默认是全局的**，跟别的语言不一样。

## 九、今天踩的坑

1. **`elif` 忘了 `then`** —— 报错却指向下一行的 `else`（bash 把 `echo` 吞进了 elif 的条件列表）。**报错行 ≠ 出错行，往上看一两行。**
2. **`[ 1=1 ]`（中间没空格）返回“真”** —— 那是“非空字符串”为真，不是比较。**必须有空格：`[ 1 = 1 ]`。**
3. **`[ 2 > 1 ]` 会创建文件 `1`** —— `>` 是重定向，比较大小必须用 `-gt`。
4. **`for f in *.txt` 无匹配时会处理一个叫 `*.txt` 的“文件”** —— 用 `[ -e "$f" ] || continue` 或 `shopt -s nullglob`。
5. **`cat f | while read` 里改的变量循环后消失** —— 管道右边是子 shell，改用 `while read ... done < f`。
6. **`return 300` 变成 44** —— return 只有 8 位，超过 255 被截断；返回数据用 `echo` + `$()`。
