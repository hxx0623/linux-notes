## 028 集 · pwd / ls / cd（课件 9.4.1–9.4.3）

### 要点

- 【课件】`pwd` 显示**当前工作目录的绝对路径**。
- 【课件】`ls [选项] [目录或文件]`：`-a` 显示所有（**含以 `.` 开头的隐藏文件**）、`-l` 列表方式。**选项可组合**：`ls -al /root`。
- 【课件】`cd [参数]` 切换目录，四个必会：绝对路径 `cd /root`、相对路径 `cd ../../root`、`cd ..` 上一级、`cd ~` 回家。

### 命令

```bash
pwd
ls / ls -a / ls -al / ls -al /etc
cd / / cd home / cd .. / cd ~ / cd ../..
```

### 【Ubuntu】

- `ls` 默认带颜色（`alias ls='ls --color=auto'`）；`ll` = `ls -alF` 也是预置别名。
- `pwd -P` 显示物理路径、`-L`（默认）逻辑路径 —— **只在软链接里才看得出区别**，见 033。
- 【补充】`cd -` 回上一个目录；`ls -h/-t/-R`；`tree -L 2`。

### 实测记录

- `cd /root` → `权限不够`：`/root` 是 `drwx------`，**进目录要的是 `x` 权限**。
- `pwd -p` → `无效的选项`：只有 `-L` / `-P`，**选项区分大小写**。
- `ls -al` 里 `.` 和 `..` 在根目录下指同一个地方；`bin -> usr/bin` 是软链接。

## 029 集 · mkdir / rmdir / touch（课件 9.4.4–9.4.6）

### 要点

- 【课件】`mkdir [选项] 目录`，`-p` **创建多级目录**（父目录不存在会自动补）。
- 【课件】`rmdir` **只能删空目录**；目录里有东西就删不掉，要删非空目录用 `rm -rf`。
- 【课件】`touch 文件名` 创建空文件。

### 命令

```bash
mkdir dog
mkdir -p animal/tiger
rmdir dog
rmdir -p animal/tiger      # 从里往外删一串空目录
touch hello.txt
```

### 【Ubuntu】

- 课件是 root 操作，`mkdir /home/dog` 在你这儿**必须 `sudo`**（`/home` 属于 root）。
- 在自己家目录 `~` 里建删都不用 sudo。

### 三种报错与含义

| 报错 | 含义 |
| --- | --- |
| `权限不够` | 你对**目标目录**没有 `w` 权限 |
| `目录非空` | rmdir 只删空目录 |
| `不是目录` | rmdir 不删文件，删文件用 `rm` |

### 实测记录

- `sudo touch hello.txt` 建出来的文件**属主是 root**，自己反而改不了 → **只在必要时用 sudo**。
- `touch` 两次，`ls -l` 看着时间没变，是因为**只显示到分钟**；看秒用 `stat 文件`。

## 030 集 · cp / rm / mv（课件 9.4.7–9.4.9）

### 要点

- 【课件】`cp [选项] 源 目标`，`-r` 递归复制整个目录。
- 【课件】`rm [选项] 文件或目录`，`-r` 递归、`-f` 强制不提示。
- 【课件】`mv 原 新` 重命名；`mv 文件 目录` 移动。
- 【课件】强制覆盖不提示用 `\cp`（反斜杠绕过别名）。

### 【Ubuntu】关键差异

Ubuntu 预置 `alias cp='cp -i'`、`mv -i`、`rm -i`，**覆盖前会问一句**。绕过别名：

```bash
\cp -r demo demo2
/bin/cp ...
```

### cp 的两种语义（最容易混）

| demo2 状态 | `cp -r demo demo2` 的结果 |
| --- | --- |
| **不存在** | 创建 demo2，内容是副本 → `demo2/{a.txt,sub}` |
| **已存在** | 把 demo 塞进去 → `demo2/demo/{a.txt,sub}` |

## 031 集 · cat / more / less（课件 9.4.10–9.4.12）

### 要点

- 【课件】`cat [选项] 文件`，`-n` 显示行号；**只能看不能改**；太长时配 `| more`。
- 【课件】`more` 分页显示，基于 vi 的文本过滤器，**只能往下翻**。
- 【课件】`less` 功能类似 more 但更强，**不是一次加载整个文件**，大文件效率高，**支持向上翻页**。

### less 常用键

| 键 | 作用 |
| --- | --- |
| 空格 / PageDown | 下一屏 |
| `b` / PageUp | 上一屏 |
| `/关键词` 回车 | 向下搜索，`n` 找下一个 |
| `g` / `G` | 开头 / 结尾 |
| `q` | 退出 |

### 【Ubuntu】

- `cat` 不带参数会**等键盘输入**，不是卡死；`Ctrl+D` 结束、`Ctrl+C` 中断。
- 实际工作直接用 `less`，more 太弱。
- 【补充】`less +F 文件` 类似 `tail -f`；`tac` 反向打印；`nl -ba` 带行号且不编空行。

### 实测印证

`less /etc/services` 搜 `http` 命中两处：注释里的 `https://` 和 `http 80/tcp www`。
**less 的搜索是纯文本匹配**，不是单词匹配。
`/etc/services` 每行四段：服务名 / 端口与协议 / 别名 / 注释。

## 032 集 · echo / head / tail（课件 9.4.13–9.4.15）

### 要点

- 【课件】`echo [选项] [输出内容]`，能直接打印环境变量：`echo $HOSTNAME`。
- 【课件】`head 文件` 默认前 10 行，`head -n5 文件` 前 5 行。
- 【课件】`tail 文件` 默认尾 10 行，`tail -n5` 尾 5 行，**`tail -f` 实时追踪文件更新**。

> ⚠️ 课件 9.4.15 把 tail 的描述写成了“显示文件的前 10 行”——**是课件的笔误**，应为尾 10 行。

### 命令

```bash
echo $HOSTNAME
echo "hello, world!"
head -n5 /etc/profile
tail -n5 /etc/profile
tail -f ~/mydate.txt        # 另开终端 echo "xx" >> ~/mydate.txt 验证实时出现
```

### 【Ubuntu】

- 日志主文件是 `/var/log/syslog`（CentOS 是 `/var/log/messages`），读它可能要 sudo。
- 【补充】`tail -F` 抗日志轮转；`head -c 100` 按字节。

### 实测记录

两台终端配合：A 里 `tail -f ~/mydate.txt`，B 里 `echo "hello, world" >> ~/mydate.txt`，A 立即冒出内容 ✅（`tail -f` 是本集最有价值的命令）

## 033 集 · 重定向 / 软链接 / history（课件 9.4.16–9.4.18）

### 要点

- 【课件】`>` **覆盖写**、`>>` **追加**：`ls -l > 文件`、`ls -al >> 文件`、`cat 文件1 > 文件2`、`echo "内容" >> 文件`。
- 【课件】`ln -s 原文件或目录 软链接名` 建软链接（类似 Windows 快捷方式）；删除用 `rm 软链接名`。
- 【课件】`history` 看历史、`history 10` 最近 10 条、`!5` 重新执行第 5 条。

### 软链接的四件事

```bash
ln -s ~/real.txt link.txt       # 建
ls -l link.txt                  # 第一列是 l，末尾 -> 目标；数字是路径长度
echo "x" >> real.txt            # 改原文件，链接读到的也变（证明不是复制）
rm real.txt                     # 删原文件 → 断链，cat 报"没有那个文件或目录"
rm link.txt                     # 删链接本身，不加 -r、不加斜杠
```

- 指向**目录**时：`cd mydoc` 后 `pwd` 显示链接路径，`pwd -P` 显示真实路径。
- **建软链接一律用绝对路径**，相对路径是相对“链接所在目录”解析的，容易断链。
- 【补充】硬链接 `ln 原 新`（不带 -s）：同一份数据两个名字，不能跨分区、不能指目录。

### 【Ubuntu】两个坑

**① `> /etc/passwd` 会立刻清空文件** —— 重定向由 shell 执行，先清空再写，**没有任何确认**。
**② `sudo 命令 > 文件` 无效**：sudo 只提升命令本身，`>` 还是当前用户在做。

```bash
ls -l /home | sudo tee /home/info.txt      # 正确写法一
sudo sh -c 'ls -l /home > /home/info.txt'  # 正确写法二
```

`tee` 默认覆盖，追加要 **`tee -a`**。

- 【补充】`2>` 重定向错误、`&>` 合并、`/dev/null` 黑洞、`Ctrl+R` 反向搜历史。

### 实测记录

- `ls -l /home > /home/info.txt` → `bash: /home/info.txt: 权限不够`。**报错前缀是 `bash:`**，
  证明是 shell 在打开文件失败，`ls` 根本没跑。
- 补刀：`cd ~` 之后再执行同一条命令**照样失败**，因为命令里写的是**绝对路径**。

## 034 集 · date / cal（课件 9.5）

### 要点

| 写法 | 输出 |
| --- | --- |
| `date` | 完整时间 |
| `date +%Y` / `+%m` / `+%d` | 年 / 月 / 日 |
| `date "+%Y-%m-%d %H:%M:%S"` | 年月日时分秒 |
| `date -s "时间"` | 设置系统时间 |
| `cal` / `cal 2026` | 本月 / 指定年份日历 |

- **格式串必须加引号**，否则空格会把参数切开。

### 【Ubuntu】

- 虚拟机里 `date -s` 改完会被拉回：`timedatectl` 显示 `System clock synchronized: yes`、
  `NTP service: active`，`open-vm-tools` + `systemd-timesyncd` 在自动对时。
- `cal` **默认没装**，在 `ncal` 包里：`sudo apt install ncal`。

### 实测记录：小写 y 是两位年

```
$ date "+%y-%m-%d"
26-10-23            ← 小写 %y = 两位年份
$ date +%F
2026-10-23          ← %F 等价 %Y-%m-%d
```

**又一次大小写陷阱**（前面还有 `$SHELL`/`$shell`、`pwd -P`/`-p`）。

### 【补充】选学

`date +%F`（= %Y-%m-%d）、`+%T`（= %H:%M:%S）、`+%A` 星期、`+%s` 时间戳、
`date -d "1 day ago"`（备份脚本常用）、`cal -3`。

## 附录 B · 自测题（10 道）

1. `ls -a` 比 `ls` 多显示什么？隐藏文件的特征是？
2. `/home` 属于 root，你在里面能 `ls` 但不能 `mkdir`，为什么？
3. `mkdir -p a/b/c` 里 `-p` 解决什么问题？
4. `cp -r demo demo2`，demo2 已存在和不存在时结果有什么不同？
5. Ubuntu 上 `cp` 覆盖文件为什么会问你一句？怎么绕过？
6. `more` 和 `less` 最本质的区别是什么？
7. `tail -f` 和 `tail -n5` 分别干什么？
8. `> 文件` 和 `>> 文件` 的区别？为什么 `sudo 命令 > 文件` 会失败？
9. 软链接的第一列是什么？删原文件后链接会怎样？删链接时为什么不能加斜杠？
10. `date "+%y-%m-%d"` 和 `date "+%Y-%m-%d"` 输出差在哪？

<details>
<summary>答案</summary>

1. 多显示 `.` 开头的隐藏文件（还有 `.` 和 `..`）；隐藏文件靠**文件名首字符是 `.`**。
2. 进目录要 `x`，改目录内容要 `w`。你对 `/home` 只有 `r-x`。
3. 父目录不存在时自动创建。
4. 不存在 → 创建 demo2 并放入副本；已存在 → 变成 `demo2/demo/...`。
5. 因为 `alias cp='cp -i'`。用 `\cp` 或 `/bin/cp` 绕过。
6. less 支持**向上翻页**，且**按需加载**不一次读完整文件，大文件更快。
7. `-f` 实时追踪新追加的内容（Ctrl+C 退出）；`-n5` 只打印最后 5 行就结束。
8. `>` 清空再写，`>>` 追加。`>` 由当前用户的 shell 执行，sudo 只提升命令本身。
9. 第一列是 `l`。删原文件后链接还在但成了断链，读取报“没有那个文件或目录”。
   加斜杠会被当成“操作目录里的内容”，有误删目标的风险。
10. 小写 `%y` 是两位年份（26），大写 `%Y` 是四位（2026）。

</details>

## 附录 C · 这两天踩的坑

| 现象 | 原因 | 解法 |
| --- | --- | --- |
| `cp -r demo deno2` 之后 `tree demo2` 报 `[error opening dir]` | **命令打错一个字母**，建了 deno2 | 排错要往前看，别只盯报错那条命令 |
| `ls -l /home > /home/info.txt` → `bash: 权限不够` | `/home` 属 root；重定向由 shell 执行 | 写成 `> ~/info.txt`，或 `\| sudo tee` |
| `cd ~` 后重跑同一命令仍失败 | 命令里是绝对路径，跟当前目录无关 | 改命令本身 |
| `sudo ls > /home/x` 仍失败 | sudo 只提升命令，重定向归 shell | `\| sudo tee` 或 `sudo sh -c '...'` |
| `cal` → 找不到命令 | Ubuntu 默认不带，在 `ncal` 包 | `sudo apt install ncal` |
| `cai link.txt` → 建议装 `emboss` | command-not-found 只做同名匹配，不懂意图 | **别装**，先确认命令名对不对 |
| `pwd -p` → 无效的选项 | 只有 `-L`/`-P`，区分大小写 | `pwd -P` |
| `date "+%y-%m-%d"` → `26-10-23` | 小写 y 是两位年 | 用 `%Y` 或直接 `%F` |
