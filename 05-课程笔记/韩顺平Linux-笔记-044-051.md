## 一、【课件】10.7 权限的 10 个字符

`ls -l` 第一列是 **10 位**，第 0 位单独一类：

| 位置 | 管什么 |
| --- | --- |
| 第 0 位 | 文件类型 |
| 第 1–3 位 | 所有者（User） |
| 第 4–6 位 | 所属组（Group） |
| 第 7–9 位 | 其他用户（Other） |

第 0 位的五种取值（课件原文）：

| 字符 | 含义 | 类比 Windows |
| --- | --- | --- |
| `-` | 普通文件 | 文件 |
| `d` | 目录 | 文件夹 |
| `l` | 链接 | 快捷方式 |
| `c` | 字符设备 | 鼠标、键盘 |
| `b` | 块设备 | 硬盘 |

**每组永远 3 个字符，位置固定**：`r` 在第 1/4/7 位，`w` 在 2/5/8，`x` 在 3/6/9，缺的用 `-` 顶上，不能省略。

## 二、【课件】10.8 `rwx` 的两套含义（本课最大难点）

| 字母 | 作用到**文件** | 作用到**目录** |
| --- | --- | --- |
| `r` | 读**内容**（`cat`/`more`/`less`） | 看**名单**（`ls`） |
| `w` | 改**内容** | 在目录内**创建、删除、重命名** |
| `x` | 当程序**运行** | **进得去**（`cd`） |

**课件原话（10.8.1）**：

> `w` 可以修改，**但不代表可以删除该文件**。删除一个文件的前提条件是**对该文件所在的目录有写权限**。

**为什么？** 删除删的不是文件内容，而是**目录里那张登记表上的一行名字**。改登记表当然要目录的写权限。

**实测证据（10-27）**：`monkey.java` 权限 `660`，八戒是组员有 `rw`，能改内容，但 `rm` 它 → `权限不够`（目录没有 `w`）。

## 三、【课件】10.9 `421` 换算 + `ls -l` 每列

### 为什么是 4/2/1

| 字母 | 十进制 | 二进制 | 位权 |
| --- | --- | --- | --- |
| `r` | 4 | `100` | 2² |
| `w` | 2 | `010` | 2¹ |
| `x` | 1 | `001` | 2⁰ |

**每组权限本质是一个 3 位二进制数**，所以只有 0–7 八种组合：

| 数字 | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 字符串 | `---` | `--x` | `-w-` | `-wx` | `r--` | `r-x` | `rw-` | `rwx` |

**不会有 8、9**。`777` 是三个独立数字，不是七百七十七。

### `ls -l` 一行七段（课件 10.9.1）

| 段 | 例子 | 含义 |
| --- | --- | --- |
| ① | `-rwxrw-r--` | 1 个类型 + 9 个权限 |
| ② | `1` | 文件：硬链接数；**目录：子目录数** |
| ③ | `root` | 所有者 |
| ④ | `root` | 所属组 |
| ⑤ | `1213` | 大小（字节）；目录显示 4096（可增长） |
| ⑥ | `Feb 2 09:39` | 最后修改时间 |
| ⑦ | `abc` | 文件名 |

**目录链接数公式：子目录数 + 2**（`.` 和父目录里那一项）。实测：`~/` 链接数 18 = 16 个子目录 + 2。

**用十进制数读**：不叫“七百六十四”，叫“**七六四**”。

## 四、【课件】10.10 `chmod`

### 符号法

| 谁 | 含义 |
| --- | --- |
| `u` | 所有者 |
| `g` | 所属组 |
| `o` | 其他人 |
| `a` | 所有人（u+g+o） |

| 运算符 | 含义 |
| --- | --- |
| `=` | 设定成这个（**该组没写的位归零**） |
| `+` | 增加 |
| `-` | 去掉 |

课件三个案例：

```bash
chmod u=rwx,g=rx,o=rx abc      # → 755
chmod u-x,g+w abc              # 相对改动
chmod a+r abc                  # 所有人加读
```

**`=` 的坑**：`chmod g=r` 会把组的 `w`、`x` 一起清掉。**但只清你指定的那一组**，`u`、`o` 不受影响。

**逗号分隔，不能空格**：`chmod u=rwx g=rx abc` 会把 `g=rx` 当成文件名。

### 数字法

```bash
chmod 751 f      # 等于 chmod u=rwx,g=rx,o=x f
chmod 755 f      # rwxr-xr-x
```

**数字法永远是“重设全部 9 位”**（等价于三个 `=` 一起写）。

### 常用数字

| 数字 | 字符串 | 用途 |
| --- | --- | --- |
| 777 | `rwxrwxrwx` | 全开（别对系统目录用） |
| 755 | `rwxr-xr-x` | 可执行程序、网站目录 |
| 750 | `rwxr-x---` | Ubuntu 家目录默认 |
| 700 | `rwx------` | 私有目录 |
| 664 | `rw-rw-r--` | 协作文件（`umask 0002` 新建） |
| 644 | `rw-r--r--` | 只读文件（课件/CentOS 默认） |
| 640 | `rw-r-----` | 自己读写、组只读 |
| 660 | `rw-rw----` | 自己+组读写、其他全无 |
| 600 | `rw-------` | 私密（`.bash_history` 等） |
| 444 | `r--r--r--` | 谁都不能改 |

## 五、【课件】10.11–10.12 `chown` / `chgrp`

| 写法 | 改所有者 | 改组 |
| --- | --- | --- |
| `chown tom f` | ✅ | ❌ |
| `chown tom:police f` | ✅ | ✅ |
| `chown :police f` | ❌ | ✅（等价 `chgrp police f`） |
| `chgrp police f` | ❌ | ✅ |
| 加 `-R` | 递归到目录下所有内容（**含目录自己**） | 同 |

### 谁需要 `sudo`（本集最重要的实践差异）

| 操作 | 课件（root） | 你（cxh） |
| --- | --- | --- |
| `chmod` 自己的文件 | 直接 | 直接，**不用 sudo** |
| `chown` 改所有者为别人 | 直接 | **必须 sudo** |
| `chgrp` 改成**自己所属**的组 | 直接 | **不用 sudo** |
| `chgrp` 改成**自己不属于**的组 | 直接 | **必须 sudo** |

**为什么 `chown` 必须 root**：否则你可以造一个恶意文件把所有者改成 `tom`，出事时记在 tom 头上（栽赃）。

**报错区分**：
- `不允许的操作`（EPERM）= 内核根本不许这个动作，跟文件权限无关
- `权限不够`（EACCES）= 你有权做这件事，但对这个对象/路径没权限

**忘了 `-r` 删用户的后果**：用户没了，家目录留下，属主显示成**数字 UID**（如 `1005 1005`）—— 就是 022 集见过的孤儿文件。

## 六、两个实战（048 / 049）

### 048 警察和土匪（课件 10.13）

角色：`police`(jack, jerry) / `bandit`(xh, xq)

```bash
groupadd police; groupadd bandit
useradd -m -s /bin/bash -g police jack        # Ubuntu 必须 -m
chmod 640 jack.txt                             # 课件第6步
chmod o=r,g=r jack.txt                         # 课件第8步 → 644
usermod -g police xh                           # xh 跳槽（换主组）
```

**课件自身矛盾**：第 7 步文字说“本组人可以读写”，第 8 步命令 `g=r` 给的是**只能读**。按文字应是 `664`，按命令是 `644`。

**课件第 11 步的小结论（全场核心）**：

> 如果要对目录内的文件进行操作，需要对**该目录**有相应的权限。

### 049 神仙和妖怪（课件 10.14）

角色：`sx`(tangseng, shaseng) / `yg`(wukong, bajie)

```bash
sudo -u wukong bash -c 'echo "i am monkey" > ~/monkey.java'
chmod 660 /home/wukong/monkey.java     # 答案：660
sudo usermod -aG yg shaseng            # 加附加组（不能写成 -G）
```

**为什么是 660**：八戒要 rw（组）→ `g=rw`；唐僧沙僧一点都不能有 → `o=---`。

**为什么能跑通**：悟空用 `-g yg` 建的，家目录 `/home/wukong` 属组是 `yg` 且权限 `750` → 组员有 `r-x` 能进，其他人（sx）进不去。**Ubuntu 家目录默认 750；CentOS 默认 700，同样这题会卡在目录上。**

## 七、050 课堂练习 2（课件 10.15）

八步综合题，用到前面 30 集：建用户 → `mkdir -p` → vim 写脚本 → `chmod u+x` → `./aa` → `rm -r` → `userdel -r` → `set-default graphical.target` → `reboot`。

关键点：

| 课件说法 | 你的实际做法 |
| --- | --- |
| “用 root 登录” | root 密码锁定 → **全程 `sudo`** |
| “用 mycentos 登录” | `sudo -iu mycentos`（`-i` = login shell，模拟真登录） |
| `mkdir test/t11/t1` | 必须 `mkdir -p`，否则中间层不存在 |
| “改成可执行文件” | `chmod u+x` 就够（664 → 764），不用 777 |
| `./aa` 的 `./` | `PATH` 里没有 `.`，不加 `./` 会报“找不到命令” |

## 八、今日踩的坑（10-27）

1. **`aa` 找不到命令，Ubuntu 建议 `apt install astronomical-almanac`** —— 又一次 `command-not-found` 只按名字匹配（同 `cai` → `emboss`）。**别装。** 根因是 `PATH` 不含 `.`。
2. **`sudo -u wukong cat ~/monkey.java` 读错文件** —— `~` 由**你的 shell** 展开，在 `sudo` 之前就变成了 `/home/cxh`。要用绝对路径或 `bash -c '...'`。
3. **`chgrp fruit ~/g.txt` 失败** —— 你不在 `fruit` 组。`chgrp` 免 sudo 的前提是**目标组是自己所属的组**。
4. **`rm 目录`（不加 `-r`）** —— 直接报 `是一个目录`，**一个字节都不删**，不是删一半。
5. **`usermod -G` 不加 `-a`** —— 会**清空**其他全部附加组（对 `cxh` 自己用会把 `sudo` 清掉）。
6. **`ls -l /home/jack/jack.txt` 不加 sudo 失败** —— 不是 shell 的锅，是**路径上 `/home/jack` 是 750，other 没有 `x`**。
7. **`userdel` 提示“邮件池未找到”** —— 不是错误，Ubuntu 默认不建 `/var/mail/用户`（CentOS 才建）。
8. **对 `=` 的范围理解** —— 它只清**指定的那一组**没写出来的位，不波及另外两组。

## 九、三条铁律（背下来，第 10 章就通了）

**① 三栏互斥，先命中先用**

```
我是所有者？   → 是，只用 u 栏，g/o 不再看
     ↓ 不是
我在所属组里？ → 在，只用 g 栏，o 不再看
     ↓ 不是
               只看 o 栏
```

**② 路径上每一层目录都要有 `x`**

```
/home/wukong/monkey.java
     ↑ 这一层没 x，后面的权限再对也没用
```

**③ 改内容看文件的 `w`；建/删/改名看目录的 `w`**

## 十、拿到需求怎么配权限（4 步）

1. **问三句**：谁是所有者？谁要能干什么？其他人给多少？
2. **定数字**：需求直接翻成 `u/g/o` 三个数字。
3. **查目录链**：这条路上每一层目录，该身份都有 `x` 吗？
4. **换身份验证**：`sudo -u 用户 命令` 实测，别只靠推理。

## 十一、自测题

1. `-rwxr-xr--` 是多少？
2. `chmod 640` 的 9 个字符是什么？组能写吗？
3. 一个文件权限 `666`，患者能删它吗？取决于什么？
4. `chmod g=r 文件` 之后，组的 `w` 还在吗？为什么？
5. 目录 `755`，别人能 `cd` 进去吗？能在里面建文件吗？
6. `chown tom:police f` 改了几样东西？

<details>
<summary>答案</summary>

1. **754**（`rwx`=7 / `r-x`=5 / `r--`=4）
2. `rw-r-----`；组**不能写**（`r--`）
3. 不一定 —— 能不能删看**目录的 `w`**，跟文件自己的 `666` 没关系
4. **不在了** —— `=` 会把组那一栏里没写出来的 `w`、`x` 归零（但只影响组，不影响 u/o）
5. 能 `cd`（有 `x`），**不能建文件**（目录没有 `w`）
6. **两样**：所有者改成 `tom`，所属组改成 `police`

</details>
