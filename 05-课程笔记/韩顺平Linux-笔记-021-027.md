## 021 集 · 用户管理(1)——课件 8.1–8.4：添加用户 / 密码 / 删除用户

### 要点

- 【课件】Linux 是**多用户多任务**系统：任何人要用系统资源，都得先向管理员申请一个账号。
- 【课件】`useradd 用户名` 创建用户，**成功后会创建同名家目录**（`/home/用户名`）。
- 【课件】`useradd -d 目录 用户名` 可指定别的家目录。
- 【课件】新用户**没有密码就无法登录**，必须 `passwd 用户名` 设置。
- 【课件】删除用户有两种：`userdel 用户名` 删号**保留**家目录；`userdel -r 用户名` 连家目录一起删。
- 【课件】课件的建议：**一般保留家目录**（人走了，资料可能还要）。

### 命令

```bash
useradd milan              # 建用户，自动建 /home/milan
useradd -d /home/m 用户名   # 指定家目录
passwd milan               # 给 milan 设密码（root 操作，不需要旧密码）
userdel milan              # 删号，保留 /home/milan
userdel -r tom             # 连家目录一起删
pwd                        # 课件顺带复习：显示当前目录
```

### 【Ubuntu】差异

| 事情 | 课件（CentOS） | Ubuntu 24.04 |
| --- | --- | --- |
| `useradd 用户名` 建不建家目录 | 建 | **不建**，必须加 `-m` |
| 新用户默认 shell | `/bin/bash` | **`/bin/sh`**（dash），要 `-s /bin/bash` |
| 更省事的写法 | 无 | `adduser 用户名`（交互式，自动建家目录+bash+同名组） |

```bash
sudo useradd -m -s /bin/bash tom    # 等价于课件的 useradd tom
sudo passwd tom
```

### 实测记录（10-22）

```
tom:x:1001:1001:,,,:/home/tom:/bin/bash    ← adduser 建的（第 5 段是 adduser 问的信息）
ap:x:1002:1002::/home/ap:/bin/sh           ← useradd 建的（没家目录、shell 是 sh）
```

删用户不加 `-r` 后，`ls -l /home` 里残留目录的属主显示成 **`1002 1002`** 数字——
因为 UID 去 `/etc/passwd` 查不到人了，只剩文件还在，叫**孤儿文件**。

## 022 集 · 用户管理(2)——课件 8.5–8.7：查询 / 切换 / 当前用户

### 要点

- 【课件】`id 用户名` 查用户的 UID、GID、所属组；**用户不存在时返回“无此用户”**。
- 【课件】`su - 用户名` 切换用户。**从高权限切到低权限不用密码，从低到高要输密码**。
- 【课件】返回原用户用 `exit` 或 `logout`。
- 【课件】`whoami` / `who am i` 查看当前用户 / 登录用户。

### 命令

```bash
id root                    # 查 root 的信息
su - tom                   # 切到 tom（横杠 = 完整登录，加载对方环境+家目录）
exit                       # 回到上一个用户
whoami                     # 当前有效身份
who am i                   # 这个终端最初是谁登录的
```

### 【Ubuntu】差异

- `su - root` **会失败**：Ubuntu 的 root 密码是锁定的（`/etc/shadow` 里密码字段是 `!`）。
  实际用的是 `sudo 命令`（要自己的密码）或 `sudo -i`（拿到 root shell）。第 026 集讲怎么给 root 设密码。
- 【补充】`whoami` 和 `who am i` 的区别：切换用户后 `whoami` 变、`who am i` **不变**（后者读终端的登录记录）。

## 023 集 · 用户管理(3)——课件 8.8：用户组

### 要点

- 【课件】组类似**角色**，把有共性权限的多个用户统一管理。
- 【课件】`groupadd 组名` 新增组，`groupdel 组名` 删除组。
- 【课件】`useradd -g 用户组 用户名` 建用户时直接指定组。
- 【课件】`usermod -g 用户组 用户名` 修改用户所在的组。

### 课件原案例

```
groupadd wudang              # 建组 wudang
useradd -g wudang zwj        # 建 zwj，直接归到 wudang 组
groupadd mojiao              # 再建一个组
usermod -g mojiao zwj        # 把 zwj 改到 mojiao 组
```

### 【Ubuntu】差异

| 想做的事 | 课件 | Ubuntu |
| --- | --- | --- |
| 建用户并指定组 | `useradd -g wudang zwj` | `sudo useradd -m -s /bin/bash -g wudang zwj` |
| 同上（Ubuntu 味） | — | `sudo adduser --ingroup wudang zwj` |
| 把已有用户加进组 | `usermod -g`（改主组） | 【补充】附加组用 `sudo adduser zwj sudo` 或 `usermod -aG` |

> ⚠️ `adduser -g` 会报 `Option g is ambiguous (gecos, gid, group)`：
> `adduser` 和 `useradd` **是两个不同程序**，选项表完全不通。`-g` 在 `adduser` 里必须写成 `--ingroup`。

### 【补充】选学

- `groupdel` 删不掉“还有人拿它当主组”的组，要先把人用 `usermod -g` 移走。
- `/etc/group` 第 4 段只记**被额外加进去的人**；主组关系在 `/etc/passwd` 第 4 段。

## 024 集 · 用户管理(4)——课件 8.9：用户和组相关文件

### 三份文件的每行含义（【课件】原样）

| 文件 | 每行是 |
| --- | --- |
| `/etc/passwd` | 用户名 : 口令 : 用户标识号(UID) : 组标识号(GID) : 注释性描述 : 主目录 : 登录Shell |
| `/etc/shadow` | 登录名 : 加密口令 : 最后一次修改时间 : 最小时间间隔 : 最大时间间隔 : 警告时间 : 不活动时间 : 失效时间 : 标志 |
| `/etc/group` | 组名 : 口令 : 组标识号(GID) : 组内用户列表 |

### 三句话记住

1. `/etc/passwd` 第 2 段是 `x`，**真密码在 `/etc/shadow`**（前者 644 人人可读，后者 640 只有 root 能读）。
2. `/etc/shadow` 第 2 段以 **`!` 开头 = 锁定**（`passwd -S` 显示 `L`）。root 默认就是 `!`。
3. `/etc/group` 第 4 段是**附加成员**，主组成员不在这里出现。

### 实测印证

```bash
sudo grep '^root' /etc/shadow
# root:!:19723:0:99999:7:::     ← 开头那个 ! 就是“锁定”
```

## 025 集 · 运行级别——课件 9.1

### 七种运行级别（【课件】）

| 级别 | 含义 |
| --- | --- |
| 0 | 关机 |
| 1 | 单用户【找回丢失密码】 |
| 2 | 多用户状态，没有网络服务 |
| 3 | 多用户状态，有网络服务（命令行） |
| 4 | 系统未使用，保留 |
| 5 | 图形界面 |
| 6 | 系统重启 |

常用 **3 和 5**。切换命令：`init [0123456]`（课件案例：5 → 3 → 关机）。

### CentOS 7 之后 / Ubuntu 都一样：用 target

```
multi-user.target  ≈ 运行级别 3
graphical.target   ≈ 运行级别 5
```

```bash
systemctl get-default                 # 看当前默认 target
systemctl set-default multi-user.target   # 改默认（下次开机生效）
```

### 【Ubuntu】要点

- 【Ubuntu】`init` 已经不是 init 了：`ls -l /sbin/init` → `init -> /lib/systemd/systemd`。`init 3` 能用是因为 systemd 内置了兼容层。
- 【Ubuntu】`sudo systemctl isolate multi-user.target` 会**立刻关掉桌面**，恢复要用 `sudo systemctl start gdm3`（必要时补 `sudo chvt 1`）。
- 【Ubuntu】**别用 `Ctrl+Alt+F1` 切虚拟终端**：VMware 把 `Ctrl+Alt` 当"释放鼠标"热键，按键进不到虚拟机。

## 026 集 · 找回 root 密码——课件 9.2

### 原理（比命令重要）

GRUB 把内核和一串启动参数交给内核，其中 `init=` 指定“开机第一个运行的程序”。把它改成 `/bin/bash`，
就**直接拿到一个 root shell，全程不需要密码**。

> 结论：**能物理接触机器并操作开机菜单 = 拥有最高权限**。这就是企业要给 BIOS/GRUB 设密码、做全盘加密的原因。

### 课件流程（CentOS）

```
开机按 e 进 GRUB → 找 linux16 那行 → ro 改 rw，末尾加 init=/bin/bash
→ Ctrl+X 启动 → mount -o remount,rw / → passwd root
→ touch /.autorelabel（SELinux）→ exec /sbin/init
```

### 【Ubuntu】四处不同

| 步骤 | CentOS | Ubuntu 24.04 |
| --- | --- | --- |
| 进 GRUB 菜单 | 默认显示 | **默认隐藏**，要先把 `GRUB_TIMEOUT` 改成非 0 |
| 内核行开头 | `linux16 /vmlinuz-…` | `linux /boot/vmlinuz-…` |
| `touch /.autorelabel` | 要（SELinux） | **不需要**（Ubuntu 用 AppArmor） |
| root 状态 | 一般有密码 | **锁定**，`passwd root` 之后才第一次可用 |

### 完整步骤（Ubuntu 实测通过）

```bash
# ① 让 GRUB 菜单显示出来（只做一次）
sudo cp /etc/default/grub /etc/default/grub.bak
sudo sed -i '/^GRUB_TIMEOUT=/d; /^GRUB_TIMEOUT_STYLE=/d' /etc/default/grub
printf 'GRUB_TIMEOUT_STYLE=menu\nGRUB_TIMEOUT=10\n' | sudo tee -a /etc/default/grub
sudo update-grub

# ② 重启，什么都别按，等 10 秒菜单出现 → 选 Ubuntu → 按 e
#    找到以 linux 开头那行：ro 改 rw，行尾加 " init=/bin/bash" → Ctrl+X

# ③ 进去之后
mount -o remount,rw /
passwd root
exec /sbin/init        # 或 reboot -f

# ④ 验收并重新上锁
sudo passwd -S root    # 显示 P
su - root              # 这次能进了
sudo passwd -l root    # 日常还是用 sudo，重新锁上
```

### 踩坑

- **UEFI 机器开机按 Esc 进不了 GRUB**，会停在固件的蓝色 **Boot Manager**。
  因为 Ubuntu 默认 `GRUB_TIMEOUT=0` + `GRUB_TIMEOUT_STYLE=hidden`，菜单根本不显示。解法就是上面第 ① 步。
- `passwd: Authentication token manipulation error` = 忘了 `mount -o remount,rw /`。

## 027 集 · 帮助指令——课件 9.3

### 两个命令（【课件】）

```bash
man ls        # 查看 ls 命令/配置文件的帮助（man [命令或配置文件]）
help cd       # 查看 shell 内置命令的帮助（cd 是内置命令，man 查不到）
```

- 【课件】`man` 里按 **`q`** 退出，空格翻页。
- 【课件】课件额外提了一句：**隐藏文件以 `.` 开头**；选项可以组合，如 `ls -al`。
- 【课件】课件原话：“如果英语不太好，也可以直接百度更直接。”

### 【Ubuntu】差异

- 中文帮助需要装 `manpages-zh`（本机已装）：`man ls` 里可用 `LANG=zh_CN.UTF-8 man ls` 试中文。
- 【补充】`命令 --help` 是最快的查法，比 `man` 短；`man -k 关键词` 可以搜相关命令。

## 附录 B · 自测题（10 道，能全答出来就算过关）

1. 在 Ubuntu 上 `useradd tom` 之后，`/home/tom` 存在吗？为什么？
2. `userdel tom` 和 `userdel -r tom` 的区别？课件建议哪种？
3. `ls -l /home` 里属主显示成数字 `1002`，说明什么？
4. `su -` 中间那根横杠有什么作用？
5. 为什么 Ubuntu 上 `su - root` 会失败？正确姿势是什么？
6. `whoami` 和 `who am i` 在切换用户后有什么区别？
7. `adduser -g wudang zwj` 为什么会报 `Option g is ambiguous`？
8. `/etc/passwd` 第 7 段是什么？`/etc/shadow` 第 2 段以 `!` 开头代表什么？
9. `isolate multi-user.target` 之后桌面没了，怎么恢复？
10. 找回 root 密码时，为什么要 `ro` 改成 `rw`，还要 `mount -o remount,rw /`？

<details>
<summary>答案</summary>

1. 不存在。Ubuntu 的 `useradd` 默认不建家目录，要加 `-m`（或用 `adduser`）。
2. 前者保留家目录，后者连家目录一起删。课件建议一般保留。
3. 该 UID 在 `/etc/passwd` 里查不到了 —— 用户已删，文件成了没人认领的孤儿文件。
4. 完整登录：切到对方家目录，加载对方的环境变量。不带横杠只换身份。
5. root 密码被锁定（`/etc/shadow` 里是 `!`）。用 `sudo 命令` 或 `sudo -i`。
6. `whoami` 变成新用户；`who am i` 仍是原来那个登录者（它读终端登录记录）。
7. `adduser` 和 `useradd` 是两个程序，`-g` 在 `adduser` 里有三个候选含义，要用 `--ingroup`。
8. 第 7 段是登录 Shell；`!` 开头表示密码被锁定。
9. `sudo systemctl start gdm3`，屏幕还停在别的虚拟终端就补 `sudo chvt 1`。
10. 不为 `rw` 内核就没法写；即使写了，根分区启动时是只读挂载的，不改它会报
    `Authentication token manipulation error`。

</details>

## 附录 C · 这三天踩过的坑（对应 021–027）

| 现象 | 原因 | 解法 |
| --- | --- | --- |
| `adduser -g wudang zwj` → `Option g is ambiguous` | `adduser` ≠ `useradd` | 用 `--ingroup`，或改用 `useradd -m -s /bin/bash -g` |
| `tail -1/etc/passwd` → `选项 -- 1` 无效 | 参数粘连，少了空格 | `tail -1 /etc/passwd` |
| `echo $shell` 无输出 | 变量名大小写，且应是 `$SHELL` | 用 `$SHELL` |
| `id user ap` | 多打了一个词 `user` | `id ap` |
| `isolate multi-user.target` 后桌面不回来 | gdm 被停，`isolate graphical.target` 不会拉起它 | `sudo systemctl start gdm3` |
| 开机按 Esc 进了蓝色 Boot Manager | GRUB 菜单默认隐藏，Esc 被固件截获 | 改 `GRUB_TIMEOUT` 再 `update-grub`，重启后别按键 |
