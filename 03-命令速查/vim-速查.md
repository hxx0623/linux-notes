# vim 速查卡

> 对应课程：016 vim 快速入门、017 vim 快捷键、018 vim 内容梳理
> 环境：Ubuntu 24.04，已装完整版 `vim`（`vi` / `vim` / `view` 都指向它）
> 一句话：**vim 没有菜单，全靠键盘；按错不可怕，`Esc` 再 `:q!` 就能跑。**

---

## 一、三种模式（先记住这个，其他都好办）

```
                按 i / a / o                    按 Esc
   ┌─────────────┐ ─────────────→ ┌─────────────┐ ─────────→ ┌─────────────┐
   │  插入模式    │                │  正常模式    │            │  命令行模式  │
   │ （能打字）   │ ←───────────── │ （默认所在）  │ ←───────── │（屏幕最下面）│
   └─────────────┘    按 Esc       └─────────────┘   回车执行   └─────────────┘
                                        ↑                          │
                                        └────── 按 : 或 / ──────────┘
```

| 模式 | 作用 | 怎么进 | 怎么出 |
| --- | --- | --- | --- |
| 正常模式 | 移动、删除、复制、撤销。**所有快捷键都在这里按** | 一打开就在这；任何模式按 `Esc` 都回这里 | 按 `i` 进插入；按 `:` 进命令行 |
| 插入模式 | 像记事本一样打字 | `i` 光标前插入 / `a` 光标后插入 / `o` 下一行新开 | 按 `Esc` |
| 命令行模式 | 保存、退出、查找替换、设置 | 按 `:`（查找用 `/`） | 回车执行完自动回正常模式 |

> **新手 90% 的“没反应”都是在插入模式里按了快捷键。快捷键前先按 `Esc`。**

## 二、三板斧（最常用，必须肌肉记忆）

```bash
vim 文件名        # 打开；文件不存在就是新建
```

打开后：按 `i` → 打字 → 按 `Esc` → 输入 `:wq` → 回车 = **保存并退出**

| 命令 | 作用 |
| --- | --- |
| `:w` | 保存，不退出 |
| `:q` | 退出（没改动才能退） |
| `:wq` | 保存并退出 |
| `:x` | 同 `:wq`（没改动时不写盘） |
| `ZZ` | 正常模式直接按，等于 `:wq` |
| `:q!` | **放弃修改，强制退出** |
| `:w 新文件名` | 另存为 |

## 三、移动（正常模式）

| 键 | 作用 |
| --- | --- |
| `h` `j` `k` `l` | 左 下 上 右（比方向键快，手不离主键区） |
| `0`（数字零） | 跳到行首 |
| `^` | 跳到行首第一个非空字符 |
| `$` | 跳到行尾 |
| `gg` | 文件第一行 |
| `G` | 文件最后一行 |
| `20G` 或 `:20` | 跳到第 20 行 |
| `Ctrl + f` / `Ctrl + b` | 向下 / 向上翻一页 |
| `w` / `b` | 按“词”向后 / 向前跳 |
| `{` / `}` | 按“段落”跳 |

## 四、编辑（正常模式）

| 键 | 作用 |
| --- | --- |
| `dd` | 删除（剪切）当前行 |
| `5dd` | 删除 5 行 |
| `yy` | 复制当前行 |
| `5yy` | 复制 5 行 |
| `p` | 粘贴到光标下一行 |
| `P` | 粘贴到光标上一行 |
| `u` | 撤销 |
| `Ctrl + r` | 反撤销（重做） |
| `x` | 删一个字符 |
| `r` + 字符 | 替换一个字符 |
| `o` | 当前行下面新开一行并进入插入模式 |
| `O` | 当前行上面新开一行 |
| `J` | 把下一行合并到当前行 |

---

## 五、查找与替换（命令行模式）

| 命令 | 作用 |
| --- | --- |
| `/关键字` 回车 | 向下查找；`n` 下一个，`N` 上一个 |
| `?关键字` 回车 | 向上查找 |
| `:%s/旧/新/g` | **全文替换**（`%` = 全文，`g` = 每行所有匹配） |
| `:%s/旧/新/gc` | 全文替换，逐个确认 |
| `:5,10s/旧/新/g` | 只替换第 5–10 行 |
| `:set nu` | 显示行号（新手建议一直开着） |
| `:set nonu` | 关闭行号 |

> `%` 和 `g` 缺一个就会漏改，这是考试和面试常考点。

## 六、卡住了怎么办（逃生指南）

| 情况 | 按什么 |
| --- | --- |
| 不知道现在什么模式 | 连按两下 `Esc` |
| 提示 `E37: No write since last change` | `:q!` 回车（放弃修改） |
| 提示 `E45: 'readonly' option is set` | 需要 sudo → `:w !sudo tee %`，或退出后 `sudo vim 文件` |
| 底部出现 `-- INSERT --` | 插入模式，按 `Esc` |
| 底部出现 `:` 或 `/` | 命令行模式，按 `Esc` 取消 |
| 屏幕花掉 / 显示乱码 | 按 `Ctrl + l` 重绘 |
| 彻底乱了想重来 | `Esc` `:q!` 退出再重新打开 |

## 七、CentOS 课程 vs 你的 Ubuntu

| 内容 | 课程（CentOS 7.6） | 你（Ubuntu 24.04） |
| --- | --- | --- |
| `vi` / `vim` | 最小化安装时只有 `vi`（vim-tiny），方向键/退格会出乱码 | 已装完整 `vim`，`vi`、`vim`、`view` 都正常，**不用改 `.vimrc`** |
| 配置位置 | `/etc/vimrc`、`~/.vimrc` | `/etc/vim/vimrc`、`~/.vimrc` |
| 中文输入 | 服务器无图形界面，只显示 | 桌面版可装中文输入法，vim 内正常显示 |
