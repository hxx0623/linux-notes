## 三、三条贯穿全课的方法论（**比任何命令都值钱**）

### ① 先确认"对方实际在找什么"，再动手改

这是**这门课里出错最多的一类**，全部是同一个病根：

| 事故 | 想当然以为 | 实际 |
| --- | --- | --- |
| `lsblk -f` 的 `41.9G` | 分区大小 | **`FSAVAIL`（剩余可用）** |
| fstab 里的 `UUID=` | 抄 `blkid` 的 `PARTUUID` | 必须用**文件系统 UUID** |
| GRUB 的配置放 `/EFI/BOOT/grub.cfg` | 改了就会生效 | GRUB 读的是 **`$prefix/grub.cfg`**（`(hd0,gpt1)/boot/grub`） |
| `dpkg -S /usr/bin/fusermount3` 查不到 | 可疑文件 | **usrmerge**（包里记的是 `/bin/…`） |
| 组名 `ooop` | 抄成 `oop` | 少一个字母，`groupdel` 说"不存在" |

> **口诀**：**命令说"没有 X"但 `grep`/`ls` 明明有 X 时 → 第一反应核对自己的输入，不要先编技术原因。**

### ② 分层定位，从整体到细节

| 场景 | 顺序 |
| --- | --- |
| 机器慢 | `top`（谁高）→ `%wa` 高就 `iotop`/`iostat` → CPU 高就 `ps` |
| 磁盘满 | `df -h`（哪个分区）→ `du -sh *`（哪个目录）→ `lsof +L1`（被删仍占用） |
| 网络不通 | `ip a`（有没有地址）→ `ip route`（有没有路由）→ `ping 网关` → `ping 8.8.8.8` → DNS |
| 服务起不来 | `systemctl status` → `journalctl -u 服务 -b` → 配置语法 |
| 开机慢 | `systemd-analyze` → `critical-chain`（**不是 `blame`**） |
| 权限不够 | 属主是谁 → 我算哪一组 → 目录链每层有没有 `x` |

### ③ 验证优先：不许凭猜

| 做法 | 例子 |
| --- | --- |
| **写完配置先验** | fstab 写完 `findfs UUID=…`；GRUB 装完 `grep root=UUID grub.cfg` |
| **改完立刻验** | `chattr +i` 后必须 `sudo touch` 试一下 + 解锁后再验一次 |
| **删完必须看** | `rm -f` 之后 `ls` 确认真的没了（**退出码 0 不代表删掉**） |
| **时间戳要分清** | `ls -l` 给的是 **mtime**；"什么时候装进来的"看 `stat` 的 **birth** |

## 五、高频踩坑速查（一条一句）

| 坑 | 解 |
| --- | --- |
| `sudo 命令 > 文件` 失败 | 打开文件的是 shell → 用 `\| sudo tee` 或 `sudo sh -c` |
| `cp 多文件 目标` 目标不存在 | 目标必须**已是目录** |
| `[ 2 > 1 ]` 创建了文件 `1` | `>` 是重定向；数字用 `-gt` |
| `cat f \| while read` 变量丢失 | 管道进子 shell → `done < f` |
| `return 300` 变成 44 | 退出码只有 0–255（300−256） |
| `for f in *.txt` 无匹配时是字面量 | `[ -e "$f" ] \|\| continue` 或 `shopt -s nullglob` |
| `source /etc/profile` 副作用 | PS1 彩色丢失 + `umask` 变 0022 |
| `adduser -g` 歧义 | 用 `--ingroup` 或 `useradd -g` |
| `chgrp` 免 sudo 的限制 | 只能改到自己所属的组 |
| 报错行 ≠ 出错行 | `if`/`elif` 缺 `then` 会在后面才报；用 `bash -n` / `shellcheck` |
| 全角空格 | `ls　-l` 变成"未找到命令" ← IME 全角态 |
| `rm` 的确认 | 回车**不算**确认；验证删除必须 `-f` + 事后 `ls` |
| `grep` 是子串匹配 | `grep 'oop'` 命中 `ooop`/`whoopsie`；精确用 `-E '^x:'` / `-w` / `-x` |
| `-perm -4000` 的减号 | 表示"**至少**含这一位" |
| 一块 vmdk 挂两次 | 报"另一个程序已锁定文件的一部分"；一机一次 |

## 六、CentOS → Ubuntu 必换清单（速查）

| CentOS（课件） | Ubuntu（本机） |
| --- | --- |
| `yum` / `rpm -qa/-ql/-qf` | `apt` / `dpkg -l/-L/-S` |
| `/etc/sysconfig/network-scripts/ifcfg-*` | `/etc/netplan/*.yaml` + **NetworkManager** |
| 网卡 `ens33` | **`ens160`** |
| `service xxx start` / `chkconfig` | `systemctl start` / `enable` |
| `setup` / `ntsysv` | 无 → `systemctl disable` |
| `firewalld --permanent` + `reload` | **`ufw allow`（立刻生效，无 permanent/reload）** |
| `netstat` | **`ss`**（`net-tools` 装了也能用） |
| `chkconfig --list` | `systemctl list-unit-files` |
| 服务名 `sshd` | **`ssh`**（且是 `ssh.socket` 按需激活，**平时没有进程**） |
| `runlevel` | `systemctl get-default` |
| `python` | `python3`（或 `apt install python-is-python3`） |
| 默认 umask 0022 | 桌面 0002（`source /etc/profile` 会变 0022） |
| `/var/log/cron` `/var/log/secure` | `journalctl -u cron` / `/var/log/auth.log` |
| `ntpdate` | `timedatectl` / `systemd-timesyncd` |
| `ulimit` 写 `/etc/profile` | 写 `/etc/security/limits.conf` 才可靠 |

> 完整 150+ 条见 [02-CentOS转Ubuntu/centos-to-ubuntu-guide.md](../02-CentOS转Ubuntu/centos-to-ubuntu-guide.md)。
